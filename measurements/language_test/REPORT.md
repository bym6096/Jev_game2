# 언어별 이름 이해도 실측 (2026-10-29)

질문: Jev가 언어별로 이름을 얼마나 알맞게 읽는가. 힘이 세거나 약한 차이는 문제가 아니라 개성으로 보고 숫자만 기록했다.
방법: 흔한 카드 개념 30개(불·용·검·유령·사과·달·바다·해골·도둑·죽음·시간 등)를 17개 언어로 옮겨 같은 질문으로 Jev에 보냄. 본 호출 510 + 반복 136 + 한 글자 이름 40 = 686회, 오류 0회. 원자료와 스크립트는 같은 폴더(`out.jsonl`, `analysis.txt`, `probe.py`, `analyze.py`, `translations.json`).

## 요약
- **정상 단어를 낙서로 막은 경우는 686번 중 0번**이다. 검문소는 언어와 상관없이 일반 명사를 잘 통과시킨다.
- **영어와 같은 답을 내는 비율**로 세 묶음으로 나뉜다. 묶음 사이 차이는 약 15~20점으로 실제 차이다(8점 이하는 오차).
  - 영어와 거의 같음(90% 이상): 중국어 간체·번체, 러시아어, 태국어, 일본어, 아랍어, 스페인어
  - 조금 약함(83~87%): 한국어, 포르투갈어(브라질), 베트남어, 독일어, 프랑스어
  - 뚜렷하게 약함(73~80%): 이탈리아어, 폴란드어, 터키어, 인도네시아어
- 모든 언어가 알맞은 속성 비율 65%를 넘었다. 기준이 된 천장은 93%인데, 영어 자신도 방패와 주사위를 `tool`로 답해서(제가 정한 정답 집합에 `tool`이 없던 탓, 언어 문제가 아님) 93%가 최대다.

## 틀린 이름 (방패·주사위는 영어도 틀려서 제외)
- 영어, 중국어, 러시아어, 태국어, 일본어: 없음
- 아랍어: سم(독) → 영혼 0.29
- 스페인어: Pan(빵) → 신화 0.57
- **한국어: 독(독) → 짐승 0.29, 용 0.28, 독 0.27 / 성(성) → 영혼 0.24.** 한 음절 동음이의어만 틀렸고 두 음절 이상은 모두 맞았다
- 독일어: Gift(독) → 돈 0.19 (영어 gift로 읽음)
- 포르투갈어: Tempo(시간) → 음악 0.57 / Lua(달) → 도구 0.33
- 베트남어: Sét(번개), Ma(유령), Bom(폭탄)
- 프랑스어: Pain(빵) → 감정 0.84 / Chat(고양이) → 언어 0.55 / Temps(시간) → 온기 0.56

## 이름 힘 (개성으로 보고만 함)
- 중국어, 러시아어, 태국어는 영어와 거의 같음(0.98~1.00)
- 일본어, 한국어, 아랍어, 스페인어는 0.94~0.96
- 독일어, 포르투갈어, 프랑스어, 이탈리아어, 폴란드어, 터키어, 인도네시아어는 0.85~0.90이고 마나가 평균 0.5~1 낮음
- 카드가 같은 개념이어도 언어에 따라 마나가 조금 다르다. 언어를 섞는 덱에서는 유럽 언어 카드가 영어 카드보다 0.5~1 마나 싸진다

## 권고
- **안전하게 지원할 언어:** 영어, 중국어(간체·번체), 일본어, 러시아어, 태국어, 아랍어
- **약한 단어가 있지만 지원 가능:** 스페인어, 한국어(한 음절 독·성 주의), 독일어, 포르투갈어(브라질), 베트남어, 프랑스어
