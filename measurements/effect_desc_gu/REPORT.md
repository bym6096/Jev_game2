# 효과 설명의 "카드" → "구슬" (2026-11-03)

화면 문구를 구슬로 바꾸면서 효과 설명에 든 "카드"(11개 효과: 집중·공명·통찰·복제·회수·변신·망각·예지·할인·흉내·봉인)도 바꿀 때 Jev 판정이 달라지는지 쟀다. 효과 선택지 설명은 Jev 질문에 그대로 들어간다(`forge.build_request`). 고유 효과 설명은 영어로 보내고, 조합 효과·주인공 패시브는 화면 표시용이라 판정과 무관하다.

방법: 이름 74개(견본 44 + 카드 관련 효과를 노린 30), 효과 질문만 같은 요청에서 설명만 바꿔 비교. 옛 설명은 두 번 재서 Jev 자체의 흔들림을 쟀다. `probe.py` → `out.json`, `run.txt`; 복제 문구 재시험 `probe_copy.py` → `out_copy.json`, `run_copy.txt`.

## 결정
- **화면에 보이는 문구는 전부 구슬**(복제는 "이 구슬을 똑같이 하나 더 만든다").
- **Jev에게 가는 효과 선택지 11개는 옛 문구("카드") 유지**: `forge.JEV_FX_DESC`. `build_request`가 이전과 바이트 단위로 같음을 확인(효과·고유·언어 줄·주인공 요청). 판정은 그대로.
- 구슬 문구로 합치고 싶으면 `JEV_FX_DESC`를 비우면 된다(복제가 약해지는 값을 감수). 새 값으로 샘플 44장은 다시 만들지 않았다(판정이 같아서 필요 없음, 문구만 바꿔 넣음).
- 실제 서버 경로 확인: 복제 인간 copy 0.89, 쌍둥이 0.73(옛 0.92, 0.75, 흔들림 범위).
