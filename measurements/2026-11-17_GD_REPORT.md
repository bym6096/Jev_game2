## 읽을 거리

1. **판정 품질은 거의 같다.** 40문항 중 38문항에서 1위가 같았고, 게임 점수 순위 상관도 0.88이다. 틀린 곳만 다르다.
   - Jev만 틀림: b1 "달지만 디저트는 아닌 것 → 꿀 바른 햄"(경계 판정, 정답 확률 0.09).
   - Gemini만 틀림: m4 "서랍이 열렸으니 상자 열쇠를 꺼낼 수 있다"(여러 물건 상호작용, 0.13).
   - 둘 다 틀림: p1 "같은 크기 쇠공·나무공 동시 낙하"(물리).
   - BRIEF_v05의 "Jev 약점"(셋 이상 조합, 간접 연쇄, 복합 논리) 문항은 이번엔 둘 다 대부분 맞혔다. 문항이 쉬웠을 수 있다.
2. **Gemini는 결정적이다.** 같은 요청이면 확률까지 똑같이 나온다. 캐시·재현·"정직함"(규칙이 몰래 안 바뀜)에는 유리하다. Jev의 작은 흔들림을 "드러난 운"으로 쓰려던 설계(LESSONS.md)라면 이 장점은 의미가 줄어든다.
3. **맥락에 더 크게 움직이는 쪽은 Jev다.** 관련 맥락 한 줄에 Jev는 확률이 평균 0.68 옮겨 갔고 Gemini는 0.49였다. 무관한 맥락에는 둘 다 0.09로 잘 버텼다. Gemini는 기준 상태에서 더 반반(0.4~0.5)으로 시작하는 경우가 많았다.
4. **말 안 되는 줄 걸러내기는 Gemini가 낫다.** 빠른 모드 낱말 늘어놓기 점수가 Jev 평균 22, Gemini 평균 8이었다. 잘 지은 줄은 Gemini가 더 후하게 줘서(227 vs 194) 좋은 줄과 나쁜 줄의 간격이 더 벌어진다.
5. **두 모델 공통의 게임 설계 문제**: 의뢰 모드에서 "뻔한 줄"이 "낱말 늘어놓기"보다 점수가 낮은 경우가 많다(Jev 7/15, Gemini 8/15만 순서를 지킴). fortune에서는 "초록 냄비가 화요일을 접는다"가 166/183점으로 잘 지은 줄을 넘었다. 판정 모델이 아니라 점수식(새로움 보너스, 운세의 신비 결) 쪽에서 볼 문제다.
6. **속도·비용**: Jev가 약 2배 빠르다. Gemini는 같은 요청을 토큰 약 0.6배로 세지만 단가가 2.4배라 실제 게임 판정은 약 1.4배 비싸다(아래 비용 절). 무료 등급 한도(분당 5만 입력 토큰)면 판정 기준 분당 약 80회라서 동시 접속자가 늘면 막힌다.

## 한계
- 문항은 이번에 새로 쓴 40+8+12쌍과 게임 줄 25개다. 문항이 쉬워 정답률 차이가 잘 안 드러났을 수 있다. 정답률을 가르려면 더 어려운 물리·상호작용 문항이 필요하다.
- 게임 줄은 조각 조립이 아니라 손으로 쓴 줄이다. 빠른 모드 길이 배율은 띄어쓰기 낱말 수로 근사했다.
- 요청 형식은 API 오류 메시지로 맞췄다. 공식 가격표가 Decisions API 문서(ai.google.dev/gemini-api/docs/decisions-api)를 가리키니 다음엔 그 문서로 형식을 다시 확인한다.

## 비용 (2026-11-17 추가)

단가 (둘 다 출력 토큰 0이라 입력만 낸다)
- Jev: 입력 $0.042 / 1M 토큰 (HANDOFF.md 기록, 공식 단가로 적혀 있음)
- Gemini Decision 1: 유료 등급 입력 $0.10 / 1M 토큰, 무료 등급 무료 (Google 공식 가격표 ai.google.dev/gemini-api/docs/pricing, 2026-11-17 확인). 질문이 여러 개여도 공통 입력은 한 번만 센다. Batch API 없음. 무료 등급은 입력이 제품 개선에 쓰이고 분당 입력 5만 토큰 한도.

같은 요청인데 세는 토큰 수가 다르다. 그래서 단가 차(2.4배)가 그대로 비용 차가 되지 않는다.

- Jev는 짧은 요청에도 약 200토큰이 더 붙는다(고정 오버헤드로 보임). 그래서 짧은 문항은 Gemini가 오히려 싸고, 지금 게임처럼 긴 규칙 글이 붙는 요청은 Gemini가 약 1.4배 비싸다.
- 규모로 보면: 판정 100만 회에 Jev 약 $43, Gemini 약 $61. HANDOFF의 가정(DAU 1,000명이 하루 1시간, 1분에 1회 판정 ≈ 월 180만 회)이면 Jev 월 약 $77, Gemini 월 약 $110. 둘 다 비용이 설계를 지배할 수준은 아니다.
- 실제 병목은 비용보다 Gemini 무료 등급의 분당 토큰 한도다. 게임 판정 한 번이 약 600토큰이라 분당 약 80회에서 막힌다. 유료 등급으로 올리면 한도는 늘지만 그때부터 위 단가가 붙는다.
