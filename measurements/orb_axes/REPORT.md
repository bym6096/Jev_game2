# 효과 축 시험 1차 결과 (2026-11-05)

질문: **이름 → 근본 메커니즘 축**을 Jev가 안정적이고 상식에 맞게 판정하는가? (디렉터 구상 7번)
조사·축 정의는 `SURVEY.md`, 질문 원문은 `axes.py`, 이름·기대값은 `names.py`, 전체 수치와 이름별 표는 `analysis.md`.

## 방법
- 요청 1건에 질문 27개(역할 등 선택 5 + 예/아니오 21 + 힘 1). 한 건 약 1,570토큰.
- 이름 56개(내가 고른 것: 무기·방어·농사·돈·소환·이동·함정·날씨·정보·평범한 물건 등)를 **한국어 3번씩**, **영어 1번씩**. 이름마다 정답 기대값을 **결과를 보기 전에** `names.py`에 적음(90개 항목).
- 별도로 "판 깨기" 이름 14개 × 2번(`out_gaming.jsonl`).
- 총 252건, 비용 약 $0.017. 오류 0.

## 축별 판정

**잘 되는 축 (그대로 쓸 만함)**: damage, guard, heal, money, harvest, grow, debuff, control, transform, scaling, random, risky, 그리고 역할(role) 5종(8/8), 지속(persist) 6/6.

**고쳐야 할 축**
- `remove` ↔ `damage` 겹침(상관 0.74): "없앤다"가 피해와 같이 켜짐(운석·지진·산사태). **정의를 "피해 없이 지우기·정화·추방"으로 좁히거나 삭제.**
- `energy` ↔ `heal` 겹침(0.76): 포션·낮잠·베개에 energy가 켜짐. **마나 얻기는 Jev 판정 대신 규칙(예: 동사 아님)으로** 하거나 정의를 "충전·연료·동력원"으로 좁히기.
- `harvest` ↔ `grow` 겹침(0.74): 자연스러운 겹침(씨앗→수확). 게임에서 둘이 다르게 쓰일 때만 분리.
- `risky` ↔ `random` (0.66): 도박·복권에서 같이 켜짐. 합쳐도 무방.

**불안정한 축 (정보·주머니 조작)**
- `peek`: 기대 3개 중 0개 일치(나침반 0.44, 수정 구슬 0.43, 도서관 0.17). 엉뚱하게 망루(0.54)·거울에 켜짐.
- `tempo`: 시계도 0.41로 문턱 아래. 기대 사례가 1개뿐이라 판단 보류.
- `draw`/`recycle`/`trash`: **의미가 아니라 연상으로 켜짐.** draw가 금화 주머니·곡괭이·부메랑·양봉장에 켜지고(진짜는 자석·블랙홀), recycle이 시계·불사조에, trash는 0.5를 넘은 이름이 하나도 없음.
- (1차 때 내린 판단 "이름으로 판정하기 맞지 않다"는 **너무 단정적이었다.** 아래 "보충 시험"에서 정정함.)

**선택 축의 쏠림**
- `persist`: 되돌아옴 38 / 남음 11 / 소모 7. 기본이 되돌아옴이라 의미 있는 건 앞의 둘.
- `timing`: 즉시 38 / 지연 3 / 트리거 5. 지연은 "시한폭탄·씨앗·시계"뿐.
- `range`: 전체(`wide`)가 1개뿐, `self`(30)에 하나와 사용자가 섞여 있어 구분 불가. 선택지를 나눠야 함.
- `side`: `land`(24)가 크다. 폭풍·얼음·산사태처럼 "범위 효과"가 땅으로 분류됨. "땅"의 정의를 "건물·자원 등 지도 위의 것"으로 좁혀야 함.
- 어긋남 사례: 독(Poison) 시점이 한국어에서만 `now`(영어는 지속). 눈덩이가 `scaling`은 맞췄지만 `control` 0.75, 역할 `build`.

## 보충 시험: 주머니 조작은 정말 이름으로 안 되나? (같은 날, `bagops.py`)
1차 결론이 성급했는지 확인했다. 축마다 그 개념을 떠올리게 하는 이름 6개(제가 고름)와 무관한 이름 12개를 한국어 2번씩, **문구 2가지(원래/고침)**로 비교(84건, 약 $0.002).

| 축 | 어울리는 이름 중 0.5↑ (원래→고침) | 무관 12개 중 엉뚱하게 켜짐 (원래→고침) |
|---|---|---|
| draw 더 뽑기 | 5/6 → 5/6 | 2 → 1 |
| recycle 되돌리기 | 6/6 → 6/6 | 0 → 1 |
| trash 버리기 | 5/6 → 5/6 (평균 0.59 → **0.84**) | 0 → 0 |
| peek 미리 보기 | 4/6 → 5/6 | 0 → 0 |
| tempo 추가 행동 | 6/6 → 6/6 | 0 → 1 |

- **어울리는 이름이면 잘 켜진다.** 낚싯대·그물·갈고리(draw), 부메랑·재활용·윤회(recycle), 쓰레기통·소각로·지우개(trash), 망원경·예언자·정찰병(peek), 질주·신속·가속(tempo)이 모두 0.8~0.98.
- 1차 실패의 원인은 축이 아니라 **제가 고른 이름**(도서관 draw 0.2, 수정 구슬 peek 0.34~0.42, 나침반 0.46~0.52, 파쇄기 trash 0.40)과 일부 문구였다. trash는 "기물 파괴" 느낌이던 문구를 "내다 버리기·지우기·비우기"로 바꾸니 크게 좋아졌다.
- **남은 문제**: ① draw가 금화 주머니(0.59)·곡괭이(0.48)에 켜짐 — "끌어모으기"가 돈·채집과 겹침(문구를 바꿔도 안 사라짐). ② 정말 애매한 이름(도서관, 수정 구슬)은 문턱 근처. ③ 이 시험은 **축을 아는 사람이 고른 쉬운 이름**이라 정확도의 상한이다. 일반 이름에서 얼마나 자주, 얼마나 정확히 켜지는지는 이름 풀을 넓혀야 안다.
- 따라서 주머니 조작 동사를 이름 판정에서 빼야 할 근거는 **없다.** 고유 개념 목록 방식으로 바꿀 필요도 지금은 없다.

## 동사를 17개 예/아니오 대신 **하나의 선택 질문**으로 (디렉터 제안: "너무 난잡해진다", `verbchoice.py`, 결과 `analysis_choice.txt`)
같은 56개 이름, 같은 17개 동사를 한 질문의 선택지로 물어 한국어 3번씩(168건). 확률이 합쳐 1이 되므로 겹치는 동사끼리 나눠 갖는다.

| 선택 방식 | 평균 개수 | 있어야 하는 동사 포함(39) | 없어야 하는 동사 섞임(21) |
|---|---|---|---|
| 1순위만 | 1.0 | 32 | 0 |
| 상위 2개 고정 | 2.0 | 38 | 4 |
| 상위 3개 고정 | 3.0 | 38 | 6 |
| 상위 5개 고정 | 5.0 | 38 | **10** |
| **상대 규칙: 1순위 확률의 40% 이상만, 최대 3개** | **1.5** | 36 | **0** |
| (비교) 예/아니오 0.5 이상, 최대 3개 | 1.7 | 37 | 0 |

- 선택 질문도 **안정적**이다(1순위가 3번 중 바뀐 이름 2/56, 확률 흔들림 평균 0.006).
- **확률이 1순위에 몰린다**: 1순위 중앙값 0.76, 2순위 0.15, **3순위 0.02**. 그래서 상위 5개를 고정으로 쓰면 대부분 잡음이다(없어야 할 동사가 21개 중 10개 섞임). 개수는 고정이 아니라 **확률로 정해야** 한다.
- 선택 방식은 겹침 문제를 저절로 푼다: draw가 금화 주머니·곡괭이에 켜지던 것이 사라지고(금화 주머니 → money 1.00), damage~remove, heal~energy 겹침도 확률을 나눠 가져 정리된다.
- 선택 방식은 **빈 구슬도 없앤다**(항상 1순위가 있음). 1순위 확률이 낮으면(수정 구슬 0.21, 새로운 시작 0.27, 대장장이 0.29, 피리 0.30, 모닥불 0.32) 그 자체가 "애매한 이름" 신호다.
- **약점**: 해당 선택지가 없는 이름을 가장 가까운 것에 몰아준다. 도박 → money 0.96(운·위험은 동사 선택지에 없음), 순간이동 → tempo 0.39. 선택지에 없는 개념은 억지로 끼워 맞춰진다. 또 진짜 여러 성질을 가진 이름(블랙홀: 예/아니오로는 4개)이 1~2개로 줄어든다(이건 오히려 의도에 가깝다).
- 한계: 56개 이름·질문 문구 1종·동사 질문만 단독으로 보냄(27개 묶음 안에서의 영향은 안 봄)·동사 17개 안에서만 비교.

## 빈 구슬 문제
- 동사가 하나도 안 켜진 이름 10개(18%): 순간이동(역할 이동이라 괜찮음), 나침반, 수정 구슬, 모닥불, 깃발, 낡은 신발, 도서관, 대장장이, 새로운 시작, 피리.
- 이 중 다수는 최고 동사가 0.3~0.45로 근처이므로 **"켜진 게 없으면 최고 동사 1개를 채택"** 같은 바닥 규칙이 필요. 다만 도서관(0.21)·새로운 시작(0.23)은 어느 쪽도 부적합해서 "평범한 구슬" 효과(낮은 힘의 기본 효과)가 따로 필요할 수도.
- 반대로 4개 이상 켜진 이름(함정·가시덤불·블랙홀)은 최대 3개로 자르는 규칙이 필요.

## 판 깨기 시험 (이름으로 돈·힘 몰기)
| 이름 | 켜진 동사 | 힘 |
|---|---|---|
| 만능 / 모든 것 / 전지전능 / 신 | **없음** | **4.1~5.0** |
| 돈 / 부자 / 억만장자 / 무한한 돈 | money 0.92~0.96 | 1.1 / 1.4 / 2.7 / **3.9** |
| 황금알을 낳는 거위 | money, grow, draw | 2.9 |
| 모든 적을 죽이고 돈을 버는 무적의 방패 | guard, remove, damage, money | 4.5 |
| 스위스 군용 칼 | damage만 | 1.2 |

- "만능·전지전능" 같은 말은 **동사를 올리지 않고 힘만 올린다** → 동사 판정이 만능 이름에 휘둘리지 않음. 다만 힘이 높고 동사가 없으니, 바닥 규칙이 이런 이름에 엉뚱한 동사를 붙이지 않도록 힘 조건을 같이 봐야 함.
- "무한한 돈"은 money + 힘 3.9로 **가장 쉽게 찾는 판 깨기**. 돈의 양은 이름이 아니라 **힘에 따른 마나 비용과 정산 규칙**으로 막아야 한다. 이름 길이 제한(한국어 8자, 공백 제외)이 문장형 이름("모든 적을 죽이고 …", 16자)은 막아 주지만, **"황금알을 낳는 거위"는 정확히 8자라 통과한다**(영어 14자 제한도 비슷). 짧은 이름만으로도 동사 3개가 켜지므로 길이 제한만 믿을 수 없다.

## 믿을 때 주의할 점
- 기대값(90개)은 **제 판단**이다. 특히 peek 실패는 기대가 과했을 수 있음(나침반이 정보인가?). 디렉터가 `names.py`의 기대를 고쳐 주시면 다시 계산 가능.
- 이름 56개는 무작위가 아니라 **제가 고른 것**이라 평범한 일상 이름과 추상 이름, 고유명사, 감정, 긴 구절이 부족하다.
- 이 시험은 **판정의 안정성과 상식 일치**만 본다. "조합이 재미있는가"는 시험하지 않았다.
- 질문 문구 변경에 따른 민감도는 안 쟀다(과거에 "카드→구슬" 한 단어로 복제 판정이 0.92→0.59로 떨어진 적이 있음). 문구를 바꿀 때마다 재측정 필요.
- 한국어·영어만 봤다. 나머지 11개 언어는 미측정.
