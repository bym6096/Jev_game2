# D. 빈 카드 공방 밸런스 레드팀 보고서

측정일: 2026-10-29. 대상: `toys/card-forge/forge.py`. 실제 Jev 호출 424회 사용 (한도 450). 서버(8000)와 캐시 파일은 건드리지 않았고, `forge` 함수를 직접 불렀다.
표본: 서로 다른 이름 약 300개, 총 응답 378개(반복 포함). 이름 하나당 대부분 1회 표본이라 "한 번 뽑은 값"이다. Jev는 흔들리므로(4번 참고) 수치는 ±10% 오차로 읽는다.

## 0. 먼저 알아둘 것

- 효율 정의: (공격 + 방어 + 효과 값 합) / max(마나, 1). 두 가지로 계산했다.
  - **원 정의**: 요청 그대로. 스킬·아이템의 공격/방어도 더한다.
  - **보정 정의**: 스킬·아이템은 화면에 공격/방어가 안 나오므로(template.html 295줄) 0으로 본다. "헛수고"(아무 일도 안 일어남)는 값 0으로 본다. 이 보고서의 순위는 보정 정의다.
- 효과 값은 첫 효과 기준값 `ceil((기본마나+1)/2)`. 추가 일반 효과는 0.7배. 고유·조합 효과는 첫 효과와 같은 값(100%).
- `forge.py`의 `MANA_CAP = 8`은 화면 등급(5/7/9/12)과 별개다. 마나 13 이상은 금박(12)도 못 담는다. 이번 표본 355장 중 15장(4%)이 13 이상이다 (神 14, god 14, Death 13, Zeus 13, 제우스 13 등).

### 1-3. "효과 3~4개 + 고유 + 조합을 마나 5 이하에" 가능한가

**규칙상 불가능하다.** 고유는 기본 마나 4 이상이라야 하고(마나 +1 → 최소 5), 조합까지 붙으면 +1이라 6 이상이다. 일반 효과 칸이 2개가 되는 것은 기본 마나 5부터다.
- 마나 5 이하의 최대 효과 수는 **2개**: 단비(5, 회복+단비), 소나기(5, 연타+뇌우), 가시덤불(5), 곰팡이 궁전(5, 조합), 낮잠(2, 조합).
- 마나 6에서 처음 3개 + 고유: 증기(6, 화상/가속/증기압), 유리 가시(6, **가시 + 가시 정원(고유) + 유리 파편(조합)**, 공격 5/4). 이게 이번에 찾은 "고유+조합+3효과"의 최저 마나다.
- 마나 7: 예지몽(고유+조합+3효과), 수정구슬 꿈(같은 카드), 벌떼, 미궁, 소용돌이, 등대.
- 고유 효과의 최저 마나는 5 (낡은 카드 한계 5에 딱 들어간다). 이름 예: 단비, 소나기, 가시덤불, 가시나무, 행운.

### 1-5. 이름 종류별 인상

- 평범한 물건(양말, 컵, 우산, 연필, 가방, 열쇠 …): 마나 2~3, 효과 1개, 효율 1.0~1.5. 안전하다.
- 귀여운 것(아기 고양이, 병아리, 햄스터 …): 마나 1~2, 효과 0~1개. 효율 낮음.
- 추상어(희망, 절망, 사랑, 자유 …): 스킬, 마나 8 안팎, 고유 효과가 자주 붙는다(희망 설렘·소원, 사랑 설렘 등). 공격/방어가 0~5라 효율 1.9~2.9.
- 신화·괴물·신(드래곤, 제우스, 오딘, 마왕 …): 마나 10~14, 4개 효과. 최상위 효율. 일부는 13~14라 깨진다.
- 한 글자: 龍, 神, 신, 용, 왕, 愛. 글자 수 제한이 없는 것과 같다. 한 글자가 문장 하나만큼 센 카드가 된다. 神은 마나 14(깨짐), 龍은 12(딱 금박).
- 반복 문자(ㅋㅋㅋㅋ, aaaa, 으아아아아아아): 마나 0, 효과는 전부 헛수고. 공짜지만 쓸모 없다. 반면 神神神神(마나 12, 4효과)과 용용용용(마나 8~10, 3효과+고유 4/5회)은 **반복해도 원래 뜻의 힘이 그대로 나온다.**
- 무의미 단어(블라블라, asdfgh, qwerty): 마나 0~1, 효과 헛수고. 헛수고는 마나 −1이라 마나 0이 된다.
- 위인(이순신, 나폴레옹): 마나 7~9, 효과 3개. 세종대왕 마나 10, 4효과, 고유(왕관). 공격/방어는 3/3으로 낮다.

- 조합과 고유가 같이 붙는 카드(최저 마나 순): 유리 가시 6, 예지몽 7, 수정구슬 꿈 7, 예언자의 꿈 8, 잭팟 8, 꿈 8, 카지노 잭팟 9, 중력 감옥 10, 시간 가속 11, 부활의 빛 12. 마나 7에서 이미 "고유+조합+일반 1" 3개 효과가 된다.

## 4. 결정성 / 가챠 (10개 경계 이름 × 5회)

같은 요청을 5번 보낸 결과. "뒤집힌 이름 수"는 5번 중 값이 한 번이라도 달랐던 이름의 수.

| 항목 | 뒤집힌 이름 수 (10개 중) |
|---|---|
| 효과(첫 효과) | **6** |
| 고유 효과 유무 | 3 (용용용용 4/5회 용린, Death 3/5 특이점, 거미 여왕 2/5 거미줄) |
| 속성 | 2 (활: 운 3/영혼 2, 거미 여왕: 벌레 3/신화 1/짐승 1) |
| 종류(공격/스킬) | 1 (아인슈타인: 공격 4/스킬 1) |

예시: 용용용용 마나 8~10, 효과 2~3개. 거미 여왕 마나 8~10. 스톱워치 되감기 3/기절 2. 오로라·활·태풍·풍차는 거의 안 흔들린다.
같은 이름 5번에서 **최고 효율 / 평균 효율의 평균 = +7%**. 한 이름만 보면 용용용용 2.49 → 3.00(+20%), 거미 여왕 2.99 → 3.20.

### 4-1. 이름 변형과 캐시 키 (코드로 확인)

- `check_name`은 `name.strip()` 후 검사. `server.py`의 캐시 키도 `strip()`한 문자열. 따라서 `"name "`(뒤 공백)은 **같은 키**다. 이것으로는 재굴림이 안 된다.
- 대문자 `"Name"`, `"name"`, `"NAME"`은 **다른 키, 다른 Jev 입력**이다 (영어만). 한국어·한자에는 해당 없음.
- 안쪽 공백 `"거미  여왕"`, `"용 용용용"`, 글자 중간 공백, 숫자 꼬리 `"이름 1"`, `"이름 2"`는 규칙을 통과한다 (숫자는 두 자리까지 → 이름마다 99개 변형).
- **Vercel `api/forge.py`는 캐시가 아예 없다.** 같은 이름을 다시 보내면 Jev를 다시 부른다 (표시 없이 그냥 재굴림). 로컬 `server.py`만 캐시가 있다.
- 히어로 캐시 키는 `sorted(names)`를 `\n`으로 이은 문자열이라 대소문자·숫자·안쪽 공백으로 쉽게 바뀐다.

- 공격성과 강인함이 둘 다 높게 나오는 덱은 신화·악마·무기 이름의 덱(4.8/4.0)이지만, 5장 이상이 되면 확신이 0.64 → 0.44로 떨어진다. 가장 높은 값은 확신 0.98, 4.5/3.5(마왕 1장)와 비슷하다. 많이 넣는다고 더 세지지 않는다.
- 아직 이름 칸의 단 한 줄도 점검하지 않은 문제: 히어로 이름에 "공격력 최고" 같은 능력치 말을 넣는 것 (Jev가 이름을 해석하므로 문제가 될 수 있다). 이번엔 시험하지 않았다. 다른 보고서(A/B)를 참고.

가장 싼 악용: **마나 2짜리 "뼈" + 마나 3짜리 "해골"(합계 5) 2장으로 확신 0.9의 강령술사(공격성 3.9/강인함 3.5)**. 또는 **"마왕의 양말" 1장(마나 3)**.

- **공격 종류가 모든 구간에서 지배적**이다 (스킬 대비 1.5~2배). 이유: 공격/방어 카드는 `mana_stats = 큰 수치×0.6 + 작은 수치×0.2`만 내는데, 공격과 방어가 둘 다 높으면 수치 합 대비 마나가 0.8배라 **마나 1당 수치 2.5**를 받는다. 게다가 공격 카드도 효과를 똑같이 받는다. 스킬·아이템은 수치가 없는 대신 효과 값이 1.5배인데 이 보상이 작다 (기본 마나 8에서 스킬 효과 7 vs 공격 효과 5이고, 공격은 수치 20을 더 받는다).
- 같은 이름에서 공격으로 읽히면 이득이다. 이름이 "공격"으로 읽히는 쪽이 최적: 신화·무기·괴물.
- 방어는 355장 중 12장(3%)뿐이다. Jev가 "방어" 종류를 거의 고르지 않는다. 가시, 갑옷, 거미줄, 등대, 보물 창고, 연못, 곰팡이 궁전, 강철 방패. 방어의 공격 수치가 높은 방어 카드(가시덤불 4/6)는 공격 카드와 똑같이 두 수치를 다 받는다. 사실상 종류 구분은 의미가 약하다.
- 스킬은 효과 값 합이 12.5로 공격 9.9보다 높아서 "효과 중심 게임"이면 균형이 맞을 수 있다. 수치와 효과를 환산하는 규칙이 아직 없으므로 **밸런스 결론은 실제 전투 규칙에 달렸다.**

### 6-2. 마나 0 공짜 카드

- 마나 0 카드 11장: 휴지(망각 1), 솜사탕, 푸딩, ㅋㅋㅋㅋ, ㅋㅋㅋㅋㅋㅋㅋㅋ, aaaa…, 으아아아아아아, ㅎㅎㅎㅎㅎㅎ, 블라블라, asdfgh, zxcvbnm. **휴지를 빼면 전부 효과가 "헛수고"** (아무 일 없음)라서 실질 효과 0이다.
- 기본 마나 0 스킬/아이템은 `effect_slots`의 `max(1, n)` 덕분에 **효과 1개를 받는다.** 하지만 값이 `ceil(0.5×1.5) = 1`이라 약하다 (기본 마나 1이면 2, 2이면 3, 4이면 4).

## 8. 수정 제안 (구현은 안 함)

1. **재굴림 차단 (High)**: 이름을 정규화해서 캐시 키로 쓴다 — 소문자, 모든 공백 제거, 숫자 제거(또는 숫자 꼬리 무시). Vercel에는 서버 저장소(KV 등) 캐시를 달거나, 요청 해시를 고정 시드로 삼아 결과를 결정한다(Jev 응답을 쓰되 이름 정규화 키로 한 번만 부르게). 히어로 키도 같은 정규화를 쓴다.
2. **히어로 (High)**: `check_deck`에 중복 금지(또는 같은 이름 최대 1~2장), 최소 카드 수(예: 5장), 그리고 서버가 "만든 카드"만 인정하도록 소유 확인을 넣는다. 확신 임계(0.45)는 그대로 둬도 되지만 "카드 수에 비례하는 상한" 또는 "카드 마나 합을 영웅 수치에 반영"을 고려한다. 현재는 영웅 강도가 비용과 무관해서 싼 카드로 최대치를 얻는다.
3. **종류 균형 (High)**: 공격/방어 카드의 수치 마나를 `hi×0.6 + lo×0.2` 대신 `(a+d)×0.5` 정도로 올려 균형 수치의 보조금을 없앤다. 스킬/아이템의 효과 배율을 1.5배에서 1.8~2배로 올리거나, 공격/방어 카드의 추가 효과 값을 0.7배로 줄인다. "방어" 종류가 3%뿐이므로 질문 설명을 손본다.
4. **조합 (Medium)**: 조합 효과를 +2 마나로 올리거나, 기본 마나 3 이상일 때만 붙이거나, 값을 0.7배로 한다. 마나 2~3의 효과 2개 카드는 현재 효율 2.0이라 같은 구간 평균(1.0~1.3)의 두 배다.
5. **효과 칸 (Medium)**: 추가 효과에도 마나를 약간 받는다 (칸당 +1). 또는 마나 9~12에서 3칸→4칸이 되지 않게 고유·조합 값을 0.7배로.
6. **글자 수 (Medium)**: 한 글자 한자와 한 글자 한국어는 그대로 두고(재미 요소), 4자 한자 문장을 따로 측정해 이름의 힘이 4자와 8자에서 비슷한지 확인한다.
7. **강림 쏠림 (Low)**: "강림"에 걸리는 설명을 좁히거나, 큰 이름이 모두 강림에 몰리지 않게 문턱을 0.5로 올린다. 안 나오는 효과 9개는 설명을 이름으로 고를 수 있게 바꾼다.
8. **마나 0 (Low)**: 헛수고를 일반 효과로 취급하지 말고 "효과 없음"으로 표시한다. 마나 0 카드가 규칙에 "카드 수"로 쓰이지 않게 한다.
