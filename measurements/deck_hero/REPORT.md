# 덱 → 주인공 판정 실측 (2026-10-28)

방법: 카드 이름 목록을 한 번에 넣어 원형(25개 중 1), 기질(8개 중 1), 공격성·강인함(0~5) 판정. 덱 38벌 × 2회 = 76요청, 입력 65,566토큰 ≈ $0.003, 응답 p50 183ms / p95 256ms. 입력은 `make_items.py`, 원자료는 `out.jsonl`.

## 결과
1. **일관된 덱(5벌)은 원형이 안정적**: 불·전쟁→pyromancer, 죽음→necromancer(0.98), 귀여움·음식→child_dreamer(1.00), 기계→engineer_inventor(0.99), 해적→pirate_sailor(1.00). 5장·10장·20장 모두 같은 원형, 같은 입력 2회 차이는 0.1 이내.
2. **섞인 덱(5벌)은 확률이 낮고 흔들림**: 1순위 확률 0.16~0.8. 20장일 때 같은 입력 2회에서 원형이 뒤집힘(mix1: pyromancer↔necromancer, mix4: engineer↔comedian, mix5_n10). 확률이 낮으면 "정체성 불분명"으로 취급하는 신호로 쓸 수 있음.
3. **카드 교체에 자연스럽게 따라 움직임**: 불·전쟁 10장 중 1장 교체=pyromancer 0.67, 3장=0.49, 5장=pirate_sailor 0.85로 전환. 귀여움 5장 교체=child_dreamer 0.51. 약간 원래 덱 쪽으로 끈적함(과반이 바뀌어야 넘어감).
4. **영어와 한국어 결과가 같음**(10장, 불·전쟁/귀여움).
5. 불·전쟁은 warrior/berserker가 아니라 pyromancer로 나옴(불이 전쟁을 이김). 원형 목록 설계 때 조정 필요.
6. 수치: 공격성은 0.3(귀여움)~5.0(불), 강인함은 0.7~3.7로 범위가 넓지 않음(강인함이 4 이상 안 나옴).

## 쓸 때 주의
