# 이전 논의에서 나온 방향 (참고용)

디렉터와 Claude가 앞서 논의한 후보들이다. **이것을 그대로 반복하거나 조금 바꾸는 것은 가치가 낮다.** 참고하되, 더 나은 방향이나 전혀 다른 방향을 찾는 재료로 쓴다. 겹치는 후보를 낼 때는 무엇이 다른지 명시한다.

## 핵심 원칙 (확정)
- Jev는 플레이어를 채점하지 않는다. 세계 안의 것이 판정하고 플레이어는 맥락을 바꾼다.
- 반복 판정은 사전 계산, 그 판에서만 생긴 것은 상한 있는 실시간 호출.

## 이전에 나온 후보 메커니즘
- M1 맥락 퍼즐: 판정 확률을 미리 공개, 맥락을 바꾸는 행동에 비용. "마음을 다루는 Into the Breach".
- M2 약속 부채: 약속하면 즉시 효과, 나중에 지켰는지 판정받음.
- M3 숨은 마음 추리: 성격·확률 숨김, 관찰로 추리. 알수록 정보 공개 단계 상승.
- M4 반응 예측 맞히기: (경고) 이전 실패의 반복, 단독 사용 금지.
- M5 해석 간극: 명령을 인물이 자기 식대로 해석. 좌절 위험.
- M6 의미 연금술: 개념 카드 두 개를 합치면 Jev가 결과를 정해진 목록에서 고름.
- M7 말로 쓴 규칙: 문장으로 된 규칙 카드, 대상이 규칙에 해당하는지 Jev가 예/아니오 판정. 자연어 Baba Is You, 빈틈 악용.
- M8 군중의 여론: 페르소나 집단 ~10개가 행동에 각자 반응.
- M9 증거와 증언: 증거를 들이밀면 증인별로 모순 여부·붕괴 판정.
- M10 소문 전달: 메시지가 사람을 거칠 때마다 이해가 변형.
- M11 블러핑: 상대가 내 행적에 비춰 내 주장을 믿는지 판정.
- M12 해석된 평판: 행적 기록으로 "자비로운가/위선적인가" 판정.
- M13 의미 기반 가치: 사람마다 물건의 가치가 다름.

## 이전에 나온 조합
- C-A 의미 퍼즐 로그라이크 = M6 + M7 (Claude가 가장 유력하다고 봄)
- C-B 거짓말쟁이의 전략 = M11 + M2 + M12
- C-C 증언의 미로 = M9 + M3 + M10
- C-D 마음을 읽는 상인 = M13 + M3 + M8
- C-E 「오합지졸」 = M1 + M3 + M2: 용병대 로그라이크 전술. 부대원 6~8명이 말로 된 특성·기억을 갖고, 명령 실행 여부를 Jev가 판정, 확정 전 확률 공개. 연설은 듣는 사람마다 다르게 판정, 약속은 기록되어 나중에 지켰는지 판정. (중세 판타지 배경은 디렉터가 식상하다고 함)
