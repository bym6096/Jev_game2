# 글꼴

- `GabiaBombaram.woff2` — 가비아 봄바람(Gabia BomBaram). 구슬에 새기는 **한국어 이름** 글꼴. 원본 TTF(디렉터가 제공)에서 한글 완성형 2,350자(KS X 1001)와 기본 라틴·문장부호만 추려 웹용 woff2로 줄인 것. 목록에 없는 희귀한 음절은 Nanum Brush Script → Song Myung 순으로 대체된다.
- **라이선스: 디렉터가 확인함(2026-11-04).** 글꼴 파일 안의 표기는 "Copyright 2015 Gabia. All rights reserved."뿐이고 사용 조건은 들어 있지 않으므로, 근거(가비아 무료 글꼴 안내 등)는 디렉터가 확인한 내용을 따른다.
- 같은 방식으로 시험했지만 쓰지 않기로 한 것: Windy Lavender(가늘어 작은 구슬에서 읽기 어려움), 가비아 솔뫼.
