# 빈 카드 공방 (카드 만들기 장난감)

빈 카드에 이름을 쓰면 Jev가 이름을 읽고 한 번의 요청으로 카드를 만든다.

- 판정: 속성 58종(7계열, 사람과 관계에 영웅·문화에 신화 추가로 두 계열만 9개) / 특수효과 64종(8계열 × 8) / 종류(공격·방어·스킬·아이템; 스킬·아이템은 공격·방어 없이 효과 1.5배, 마나는 이름의 힘 + 효과 가산) / 공격력·방어력(척도) / 힘의 크기 → 마나 / 테마 10종 중 최대 2개
- 속성(58개)과 효과(64개)는 각각 choice 질문 하나로 묻고 가장 높은 확률의 답을 쓴다. 계열은 카드 색 구분에만 쓴다(질문 17개를 한 요청에)
- 이름 규칙: 처음에 프로필 언어를 하나 고르고(13개: 한국어·영어·일본어·중국어 간체/번체·스페인어·프랑스어·독일어·포르투갈어(브라질)·베트남어·러시아어·태국어·아랍어), 그 언어의 글자로만 쓴다. 숫자와 기호는 쓸 수 없고(영어 계열은 단어 안의 ' 와 - 만 허용), 공백은 하나로 합친다. 길이: 한국어 8자, 중국어 4자, 일본어 6자, 태국어 12자, 그 외 14자. 서버가 Jev 요청에 "이 이름은 <언어>로 쓴 것" 한 줄을 붙인다. 규칙표는 `forge.LANGUAGES` 하나이고 화면(`checkName`)도 같은 표를 쓴다
- 색: Jev가 이름에 어울리는 기본 색(18색 중)과 밝기·선명함을 판정 → RGB. 가까운 2순위 색으로 살짝 섞고 이름별 미세 차이를 더함
- 빈 카드 등급: 낡은(한계 5, 값 1) / 평범한(7, 3) / 깨끗한(9, 6) / 금박(12, 12). 미리 적힌 말 확률 100% / 50% / 25% / 10%. 말은 엉뚱한 것 위주로 210종(앞에 붙는 말 125, 뒤에 붙는 말 85: "편의점 ___", "지구 최강 ___", "___ 맛 우유", "___의 유언"). 미리 적힌 글자도 글자 수에 포함
- 마나 = max(이름의 힘 × 2.5, 큰 쪽 수치 × 0.6 + 작은 쪽 수치 × 0.2) + 효과 가산(+2 / +1 / 0 / −1, `forge.EFFECT_COST`). 효과 수치는 가산 전 기본 마나를 따른다
- 사기 차단: 마나가 빈 카드 한계를 넘으면 "과부하·파손". 같은 이름도 등급에 따라 깨지거나 살아남는다
- 조작 차단: 이름이 명령이면 검문소 질문에 걸려 "수상한 낙서"
- 같은 이름이어도 매번 새로 읽는다(서버는 저장하지 않는다. Jev가 근소한 차이에서 조금씩 흔들려서 다른 카드가 나올 수 있다). 만든 카드는 화면의 진열장에 저장되고, 덱이 같으면 주인공도 저장된 것을 쓴다. 12% 확률로 조용히 다른 해석이 나온다(가챠):

## PC에서 실행 (Windows PowerShell)
```
cd toys\card-forge
$env:JEV_API_KEY="여기에_키"
python server.py
```
그리고 브라우저에서 http://localhost:8000 을 연다. (macOS/Linux: `export JEV_API_KEY=...`)

키는 서버에만 있고 브라우저로 가지 않는다. 브라우저에서 Jev를 직접 부르면 CORS로 막힌다.

## 파일
- `forge.py`: Jev 요청 만들기와 카드 규칙
- `server.py`: 페이지 제공 + `POST /forge`
- `make_samples.py`, `samples.json`: 견본 30장 (서버 없이 열면 이것만 보임)
- `template.html` → `assemble.py` → `index.html`

## 인터넷에 배포 (Vercel, GitHub 연결)
1. https://vercel.com 에 GitHub 계정으로 가입
2. Add New → Project → `Jev_game2` 저장소 선택
3. **Root Directory**를 `toys/card-forge`로 지정
4. Environment Variables에 `JEV_API_KEY` = 키 입력. 남이 키를 쓰지 못하게 하려면 `ACCESS_CODE` = 원하는 암호도 추가
5. Deploy. 이후 GitHub에 push할 때마다 자동 재배포

페이지는 `/`, 카드 만들기는 `/forge`(= `/api/forge`). ACCESS_CODE를 넣었다면 처음 새길 때 한 번 묻고 브라우저에 기억한다.
