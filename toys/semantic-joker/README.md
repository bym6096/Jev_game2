# 심야 감정소 (의미 조커 장난감 v0)

발라트로식 점수 계산에서 조커 조건을 "의미"로 쓰고 Jev가 판정한다.

- 물건 20개 × (기본 / 불탄 / 얼어붙은) = 60가지, 감정사(조커) 조건 10개
- Jev 판정은 미리 받아 둔 값(`jev_answers.jsonl`, 60요청, 약 $0.001). 실시간 판정은 아직 없음
- 점수 = (10 × 물건 수 + 칩 감정사 합) × (1 + 배수 감정사 합) × 점쟁이 곱. 감정사마다 "물건마다 값 × 취향(Jev 확률)"
- 빚 목표: 400 / 1,500 / 4,000 / 9,000 / 18,000, 기한마다 패 4번, 돌려보내기 3번

다시 만들기: `python3 -I build_items.py` → `python3 -I ../../tools/jev_run.py jev_items.json jev_answers.jsonl --max 60` → `python3 -I assemble.py`
