### Idea 2: 막힌 길 (말이 곧 도구인 원정)
| Field | Content |
|---|---|
| **Core loop** | 길이 막히면 그 앞의 존재가 원하는 것이 한 줄로 나옴("강이 얼어붙어 건널 수 없다") → 가방의 구슬(최대 3개) 중 하나를 쓰거나 새 이름을 새김 → Jev가 "충족 / 부분 / 빗나감 / 반대"를 확률로 판정 → 결과대로 통과·손해·뜻밖의 길 → 다음 장면. 구슬은 남아서 다음 장면에 다시 쓸 수 있고, 한계를 넘는 말은 파손. 실패 = 보급(체력)이 바닥 |
| **Why now** | 같은 개념(아무 말이나 쳐서 문제를 푸는 게임)으로 검색해도 2026년 인디 경쟁작은 못 찾았고, 가장 가까운 것은 2012년대 Scribblenauts Unlimited뿐임(Steam 상점 목록, 검색 1회라 근거는 얇음). LLM을 규칙에 쓴 사례는 Hex Judge(2026-07, 개발사 보도자료)뿐이고 반응 수치 없음 |
| **Lifecycle stage** | emerging (추정). 창은 확인 못 함 |
| **Twist** | 음소거 3초 클립: 얼어붙은 강 앞에 "태양"이라고 새기자 구슬이 달아오르고 강이 녹음. 또는 "고래"라고 써서 뜻밖에 반대 결과 |
| **Keep vs change** | 유지: 말이 곧 해법인 창의성의 쾌감(Scribblenauts), 짧은 장면 단위(하데스류 취향). 변경: 정해진 사전이 아니라 Jev가 의미로 판정, 결과가 확률이라 "반대"와 "부분"이 나옴, 구슬이 가방에 남아 재사용·파손 선택이 생김 |
| **Automation lever** | 장면은 (존재, 원하는 것) 템플릿에서 생성. 각 장면마다 후보 단어 수십 개를 Jev로 돌려 "충족이 1개 이상 존재하는지" 사전 검증(오프라인, 센트 단위 비용). 판 안에서는 첫 답을 저장 |
| **Social hook** | 「원정 일지」: 장면별로 내가 쓴 말과 결과를 한 줄씩 공유(웃긴 오판정 장면 위주). 일일 시드 가능 |
| **Monetization** | 근거 없음(PC 유료 가정). 가격대는 이번 스캔에서 확인 못 함 |
| **MVP scope** | 한 화면: 장면 문장 + 구슬 3칸 + 결과 줄. 장면 8개, 한국어+영어. 기존 forge 서버 재사용. 약 2주 (estimate) |
| **Not in MVP** | 분기 지도, 아이템 상점, 이야기 연출, 13개 언어, 덱·주인공 성장 |
| **Kill switch** | 사내 기준: 테스터가 같은 장면에서 다른 말을 스스로 더 시도하는 비율, "뜻밖의 결과"를 남에게 보여 주려는 행동. 임계값은 디렉터가 정함. 사전 측정: 장면 30개 × 단어 20개에서 Jev 판정이 사람 판단과 얼마나 맞는지(기준은 디렉터가 정함) |
| **Risks** | ① Jev의 "충족" 판정이 너무 후하거나 인색함 → 사전 측정으로 장면 문장 조정 ② 최적 단어가 퍼짐 → 장면이 생성형이라 큰 문제 아님 |
| **Scores** | 3 · 3 · 3 · 2 · 4 · 3 · 4 = 22/35 |
| **이전 후보와의 차이** | 이전 M7(말로 쓴 규칙)·C-A(의미 퍼즐)는 규칙 문장을 쓰는 퍼즐. 이쪽은 낱말 하나를 구슬로 새기고 존재가 반응하는 원정 |

### Idea 3: 함정 설계자 (내가 짓는 지키기)
| Field | Content |
|---|---|
| **Core loop** | 밤마다 침입자(성향이 다른 무리)가 3개 방을 지나 보물에 접근 → 낮에 방마다 구슬 1개를 놓음. 구슬은 내 말로 만든 함정·수호자(Jev가 속성·효과·세기를 정함) → 밤이 오면 침입자가 자동으로 지나가며 결과가 펼쳐짐 → 보물이 지켜지면 다음 밤. 실패 = 보물 도난 |
| **Why now** | 역(逆) 던전 장르가 여러 작품으로 형성돼 있음: Legend of Keepers(얼리 액세스 졸업), MINOS, Infamous Keepers(2027 초 예정), This Is Not A Dungeon(출시일 자료마다 다름) (Steam 상점 검색, 날짜 미확인). 로그라이크 수요 자체는 큼(Steam 로그라이크 총매출 약 5억 달러, 2026 상반기, 2차 자료) |
| **Lifecycle stage** | rising (추정), 소규모 틈새 |
| **Twist** | 음소거 3초 클립: 침입자 무리가 방에 들어서고, 내가 새긴 "거울"이라는 함정이 그들의 공격을 되돌려 줌 |
| **Keep vs change** | 유지: 준비하고 결과를 지켜보는 설계자의 재미, 침입자 성향 파악. 변경: 함정을 고르지 않고 말로 지음(무한한 어휘) |
| **Automation lever** | 침입자는 (성향, 약점·내성 속성) 조합을 시드로 생성. 방마다 막을 수 있는 속성이 존재하는지 자동 검증 |
| **Social hook** | 「밤의 기록」: 침입자가 내 함정에 걸리는 장면 요약. 웃긴 함정 이름 공유 |
| **Monetization** | 근거 없음 |
| **MVP scope** | 한 화면: 방 3개 + 구슬 놓기 + 자동 재생. 침입자 6종, 10밤. 약 2~3주 (estimate) |
| **Not in MVP** | 방 확장, 보물 종류, 이야기, 다국어 13개, 덱 |
| **Kill switch** | 사내 기준: 결과 재생을 끝까지 보는 비율, 다음 밤을 스스로 시작하는 비율. 임계값은 디렉터가 정함 |
| **Risks** | ① 승패가 표(상성)로 거의 결정되면 "표만 있음"이 됨 → 효과(속임, 도주, 분열 등) 판정을 실시간으로 넣음 ② 장르 경쟁작이 이미 있음 → 말로 짓는 함정이 클립에서 보여야 함 |
| **Scores** | 3 · 3 · 3 · 2 · 3 · 3 · 4 = 21/35 |
| **이전 후보와의 차이** | 이전 후보에는 "플레이어가 세계를 설계하는" 역할 반전이 없었음 |

### Idea 1: 일행 (이름이 곧 성격인 동료)
| Field | Content |
|---|---|
| **Core loop** | 야영지에서 빈 구슬에 이름을 새김 → 이름에서 동료 하나가 태어남(Jev가 원형·기질을 정함) → 길에서 사건이 생기고 선택지가 나옴 → 데려온 동료 중 누구를 앞세울지 고르면, 그 동료가 선택지를 고르는 확률을 Jev가 판정해 그대로 굴림 → 결과와 동료 사이 관계가 변함 → 끝까지 가거나 일행이 흩어짐 |
| **Why now** | 가장 Jev다운 사용: 판정이 "정해진 선택지 + 확률"이라는 Jev의 출력 형식과 그대로 맞음. 생물 수집 + 로그라이크 계열이 Steam에서 흥행한 사례(Mewgenics, 2026-02, 헤드라인만 확인). LLM이 만든 캐릭터가 규칙에 들어간 사례는 Hex Judge 정도(2026-07) |
| **Lifecycle stage** | emerging (추정) |
| **Twist** | 음소거 3초 클립: 같은 사건에 "불사조"와 "토끼"라는 이름의 동료가 서로 다른 선택을 하고, 선택 확률 막대가 보임 |
| **Keep vs change** | 유지: 일행을 꾸려 길을 가는 로그라이크(Darkest Dungeon·FTL류 이벤트 구조). 변경: 동료를 고르지 않고 이름으로 짓고, 동료의 행동이 Jev 확률에서 나옴. 전투 카드 없음 |
| **Automation lever** | 사건은 (상황, 선택지 3개) 템플릿으로 생성. 원형 25종 × 사건 N개의 선택 분포를 미리 측정해 이상치를 걸러냄 |
| **Social hook** | 일행 초상 + 이야기 로그("불사조가 다리를 불태웠다") |
| **Monetization** | 근거 없음 |
| **MVP scope** | 동료 4명, 사건 12개, 관계 수치 1개, 한국어+영어. 약 3~4주 (estimate) |
| **Not in MVP** | 전투, 장비, 메타 성장, 다국어 13개, 분기 이야기 |
| **Kill switch** | 사내 기준: 같은 사건에서 동료별로 선택이 갈리는지(사전 측정), 테스터가 다음 판에 동료 이름을 바꿔 시도하는 비율 |
| **Risks** | ① 가정 미검증: 이름에서 나온 성격이 사건 선택에 일관되게 반영되는지(이전 라운드 A03+에서도 같은 가정이 있었고 이 프로젝트에서 확정되지 않음) → 약 500요청(약 $0.06, estimate)으로 사전 측정 ② 효과가 안 느껴지면 그냥 랜덤 이야기가 됨 |
| **Scores** | 2 · 3 · 3 · 2 · 3 · 3 · 4 = 20/35 |
| **이전 후보와의 차이** | C-E 「오합지졸」은 주어진 부대원에게 명령을 내리는 구조. 이쪽은 동료가 플레이어의 구슬 이름으로 태어나고 명령·연설 없이 "누가 나설지"만 고름 |
