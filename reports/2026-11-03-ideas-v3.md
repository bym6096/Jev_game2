# Idea Set v3 — 2026-11-03

> **v2(`2026-11-03-ideas-v2.md`)를 대체합니다.** v2의 「막힌 길」「일행」은 구슬을 "말"로만 썼습니다. 이 프로젝트의 기믹은 **이름을 적으면 그 특성에 걸맞은 수치 객체가 생성되는 것**입니다: 속성(98), 효과(64, 최대 3개), 고유 효과(64), 조합 효과(28쌍), 마나, 공격·방어·힘, 색, 크기(마나), 등급별 한계와 파손. 이 객체가 게임의 재료가 되도록 다시 짰습니다. 구성(수치 종류)은 바꿔도 되지만 기믹은 유지합니다.
> **뺀 구조:** 점수·쿼터·빚 갚기, 손패/마나 턴제 카드 전투.
> **전제:** 웹/PC, 예산·인원 미확인. 근거 없는 항목은 채점표(rubric)의 낮은 쪽 점수를 줬습니다. 채점표는 재미를 재지 못합니다.

## 걸러진 것
- 「막힌 길」「일행」(v2): 말만 쓰고 생성된 수치 객체를 쓰지 않음
- 이름 무기고 서바이벌(레벨업 때 이름 새김): 뱀서류는 포화(이전 스캔)이고, HANDOFF에서 "전투가 끊김"으로 보류했던 안
- 생태계·배치 퍼즐: 객체끼리의 상호작용을 Jev가 못해서 표로 대신해야 함(이전 라운드 "표만 있음" 사유)

### Idea A: 구슬 가방 (크기 = 마나인 배치 + 자동 결투)
| Field | Content |
|---|---|
| **Core loop** | 결투에서 이기면 빈 구슬 1개 → 이름을 새김 → Jev가 구슬 객체를 만듦 → 가방 칸에 배치(구슬 크기 = 마나 = 차지하는 칸) → 인접한 같은 계열은 강화, 조합 쌍이 맞으면 ◆ 발동 → 자동 결투(구슬들이 자기 효과를 시간순으로 발동) → 상대 가방을 이기면 진행. 패배 누적이면 끝, 금박 보스까지 가면 승리 |
| **Why now** | 인벤토리형 자동 전투가 흥행한 뒤 후속이 이어지는 중: Backpack Battles(2025-06 얼리 액세스, Steam 평가 91% / 20,540건, Nodal 2025), 후속 Grid Warriors: Battles(2025), Rune Tavern(2026), Auto Cats(2026-10-01 예정), Topdeck Automat(2026-11-16), Guildrun(2026년 중 예정) (Steam 상점·보도자료 검색, 날짜는 대부분 예정치) |
| **Lifecycle stage** | rising~peaking (추정). 창 길이는 확인 못 함 |
| **Twist** | 음소거 3초 클립: "수박"을 새기자 초록 구슬이 튀어나와 가방 한쪽에 박히고 옆의 물 구슬과 같이 빛남. 크기만 봐도 센 이름인지 보임 |
| **Keep vs change** | 유지: 배치로 시너지를 만드는 재미, 자동 결투(Backpack Battles). 변경: 아이템을 상점에서 사는 게 아니라 이름으로 짓고, 돈 경제가 없음. 크기가 값(마나)이라 센 이름은 자리를 먹음 |
| **Automation lever** | 상대 가방은 이름 사전 수백 개를 Jev로 미리 구슬화해 조합. 효과 64개는 동작 유형 6~8종으로 묶어 구현. 규칙 엔진끼리 자동 시뮬레이션하면 승률(난이도)을 비용 없이 확인 가능 |
| **Social hook** | 내 가방 스크린샷(구슬 이름만 새겨진 배치) |
| **Monetization** | 근거 없음 (PC 유료 가정) |
| **MVP scope** | 4×4 가방, 자동 결투 재생, 상대 가방 8개, 한국어+영어. 약 4~5주 (estimate) |
| **Not in MVP** | 주인공 원형(덱→주인공), 비동기 대전, 13개 언어, 효과 64개 전부 개별 구현 |
| **Kill switch** | 사내 기준: 졌을 때 이유를 설명할 수 있는지, 가방을 다시 짜는 시도 횟수, 두 번째 판 시작 비율. 임계값은 디렉터가 정함 |
| **Risks** | ① 자동 결투 규칙과 균형이 무거움(HANDOFF: 밸런스 보류 중) → 효과를 동작 유형으로 묶어 시작 ② 장르 경쟁 → 이름이 곧 아이템인 점이 클립 중심에 있어야 함 |
| **Scores** | 2 · 3 · 3 · 2 · 3 · 3 · 4 = 20/35 |

### Idea B: 주문서 공방 (조건에 맞는 구슬 만들기 퍼즐)
| Field | Content |
|---|---|
| **Core loop** | 주문서가 나옴("물 계열 · 회복 효과 · 마나 6 이하 · 방어 5 이상") → 구슬에 이름을 새겨 Jev가 만든 객체가 조건을 채우는지 확인 → 맞으면 납품, 아니면 그 구슬은 소모 → 제한된 구슬로 주문을 모두 채우면 다음 장(조건이 늘고, 이전에 납품한 구슬을 부품으로 요구하거나 두 구슬이 ◆ 조합을 이뤄야 함). 실패 = 구슬 소진. 마나가 등급 한계를 넘으면 파손 |
| **Why now** | "조건에 맞는 물건을 말로 만드는 퍼즐 로그라이트"는 직접 경쟁작을 못 찾음(검색 1회). 가까운 것: Potion Craft(제작 시뮬, 로그라이트 아님; PCGamesN "페스티벌의 깜짝 히트"), Flask & Fury(실시간 양조 액션 로그라이트), Steam 앱 3926070(재료가 퍼즐판을 정함, 2026 Q2 예정) (Steam 상점 검색, 날짜 미확인) |
| **Lifecycle stage** | emerging (추정). 창 길이는 확인 못 함 |
| **Twist** | 음소거 3초 클립: 조건 카드에 체크 칸이 4개 있고, "핫초코"를 새기자 구슬이 만들어지며 체크가 하나씩 켜짐. 마지막 칸만 빠져 아쉬워하는 장면, 또는 구슬이 금이 가며 깨지는 장면 |
| **Keep vs change** | 유지: 재료가 결과를 정하는 제작 시뮬의 쾌감. 변경: 재료를 고르지 않고 아무 말이나 새김. AI가 정하는 숨은 규칙(이름이 수치로 바뀌는 방식)을 실험으로 알아내는 퍼즐 |
| **Automation lever** | 주문서는 (속성, 효과, 수치 상·하한) 제약 생성기로 만들고, 후보 이름 수백 개를 Jev로 돌려 주문마다 해가 몇 개인지 확인(해 0이면 폐기, 너무 많으면 조건 추가). 오프라인 비용은 센트 단위 (estimate, HANDOFF 단가 기준) |
| **Social hook** | 일일 주문서: 같은 조건을 몇 번 만에 풀었는지 + 구슬 색 줄(이름은 숨김) |
| **Monetization** | 근거 없음 |
| **MVP scope** | 한 화면: 주문서 + 구슬 입력 + 결과 객체 + 체크 칸. 주문 조건 3종류(속성/효과/수치), 한국어+영어. 기존 forge 서버와 구슬 화면 재사용. 약 1~2주 (estimate) |
| **Not in MVP** | 부품 조합 주문, 일일 서버, 13개 언어, 성장 요소 |
| **Kill switch** | 사내 기준: 주문 하나당 시도 횟수 분포(너무 쉽거나 너무 막막하지 않은지), 스스로 다른 계열을 시도하는 비율. 임계값은 디렉터가 정함. 사전 측정: 주문 30개의 해 개수 분포 |
| **Risks** | ① 시행착오 반복(폐기된 「심야 감정소」의 "선택이 뻔해 재미없음" 재현) → 조건을 2~3개 조합으로 키우고 부분 피드백 제공 ② 현재 "같은 이름 ≠ 같은 카드"(12% 가챠) 규칙이라 같은 이름을 다시 쓰면 다른 구슬이 나올 수 있음 → 퍼즐에서는 운이 되므로 이 모드에서는 규칙을 어떻게 할지 디렉터 결정 필요 |
| **Scores** | 4 · 4 · 3 · 2 · 4 · 3 · 4 = 24/35 |

### Idea C: 함정 설계자 (내 구슬로 지키는 밤)
| Field | Content |
|---|---|
| **Core loop** | 낮: 방 3개에 구슬을 새겨 놓음(밤마다 쓸 수 있는 마나 총량 안에서) → 구슬의 공격·방어·효과·속성이 곧 함정·수호자 성능 → 밤: 침입자 무리(체력·속도·내성이 다름)가 방을 지나며 구슬이 자동 발동 → 보물이 지켜지면 다음 밤. 구슬은 방어 수치만큼 닳아 재사용 가능. 10밤 |
| **Why now** | 역(逆) 던전 장르: Legend of Keepers(얼리 액세스 졸업), MINOS, Infamous Keepers(2027 초 예정), This Is Not A Dungeon(출시일 자료마다 다름) (Steam 상점 검색, 날짜 미확인) |
| **Lifecycle stage** | rising (추정), 틈새 |
| **Twist** | 음소거 3초 클립: 침입자 무리가 방에 들어서고, 내가 새긴 "거울" 구슬이 공격을 되돌려 줌 |
| **Keep vs change** | 유지: 준비하고 결과를 지켜보는 설계자의 재미. 변경: 함정을 고르지 않고 말로 지음, 구슬이 닳음 |
| **Automation lever** | 침입자는 (성향, 약점·내성) 시드로 생성, 방마다 막을 수 있는 속성이 존재하는지 자동 검증 |
| **Social hook** | 「밤의 기록」: 침입자가 내 함정에 걸리는 장면 요약 |
| **Monetization** | 근거 없음 |
| **MVP scope** | 한 화면: 방 3개 + 구슬 놓기 + 자동 재생. 침입자 6종, 10밤. 약 2~3주 (estimate) |
| **Not in MVP** | 방 확장, 이야기, 13개 언어, 덱 |
| **Kill switch** | 사내 기준: 결과 재생을 끝까지 보는 비율, 다음 밤을 스스로 시작하는 비율 |
| **Risks** | ① 승패가 상성 표로 결정되면 구슬 수치가 무의미해짐 → 효과(속임, 도주, 분열 등)가 결과를 바꾸게 설계 ② 장르 경쟁 → 말로 짓는 함정이 클립에서 보여야 함 |
| **Scores** | 3 · 3 · 3 · 2 · 3 · 3 · 4 = 21/35 |
