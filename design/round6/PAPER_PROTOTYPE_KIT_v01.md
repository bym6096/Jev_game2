## 1. 공통: 사람이 Jev 역할을 할 때의 규칙

### 1.1 역할
- **플레이어**: 1명.
- **진행자**: 규칙·상태·기록 담당.
- **Jev 역할**: 판정만 한다. 진행자와 다른 사람이어야 한다.
- **손 표 진행자**: A/B 세션용. Jev 역할과 같은 자리에 앉아 같은 방식으로 쪽지를 낸다.
- 칸막이를 둔다. Jev 역할은 판정자 카드와 지정된 입력만 보고, 플레이어의 표정·발화·목표를 보지 않는다.

### 1.2 출력 형식(Q19 준수)
- 쪽지 한 장에 다음 셋만 적는다.
  1. **선택지 1개**
  2. **확신 3단계**(확고 / 보통 / 망설임)
  3. **가장 영향 준 것 1개**(입력 항목 번호)
- **설명은 금지한다.** 말로 이유를 붙이지 않는다.
- 진행자가 쪽지를 받아 규칙대로 처리한다.

### 1.3 확률 기준표(Jev 역할이 확신을 고르는 기준)
| 확신 | 의미 | 대응 원시 마진(규칙 처리용) |
|---|---|---|
| 확고 | "다른 답은 거의 생각나지 않는다" | ≥ 0.30 |
| 보통 | "2위가 떠오르지만 1위가 분명하다" | 0.10~0.30 |
| 망설임 | "1·2위 사이에서 고민된다" | < 0.10 |

- 확률 숫자가 필요한 후보(A03 c_j)는 5구간 단어로 적는다: 거의 없음 0.05 / 낮음 0.25 / 반반 0.5 / 높음 0.75 / 거의 확실 0.95. 세 선택지 합이 대략 1이 되게 한다.

### 1.4 Jev 흉내 지침(실제 Jev 경향을 흉내 내는 법)
1. **상식 우선**: 판정자 카드의 성향과 최근 기록에 반응한다. 기발하게 만들지 않는다.
2. **최근 기록에 민감, 무관 기록에 둔감**: 판정 대상과 직접 관련된 기록이 있으면 그쪽으로 움직인다. 관련 없는 기록은 무시한다(국소성 가정).
3. **일관성**: 같은 입력이면 기록지를 보고 같은 답을 한다(캐시).
4. **오류 주입**: 진행자가 몰래 주사위를 굴려 6이 나오면 "이번엔 의외로" 쪽지를 준다. Jev 역할은 상식과 다른 선택지를 고른다. 실제 Jev 정확도(약 78.6%, 2차 자료)를 흉내 낸 것이다.
5. **극단 모드(대조 세션용)**: "망설임"을 쓰지 않고, 확고를 기본으로 한다. 실제 Jev가 과신하는 경우(C-R16)를 흉내 낸다. 실측 0단계 결과가 나오면 기본 모드를 그 결과에 맞춘다.

### 1.5 한계(보고서에 반드시 적는다)
- 사람은 실제 Jev보다 정확하고 이야기가 되게 판정한다(낙관 편향, C-R12).
- 위치 편향, 묶음 간섭, 극단 집중 같은 기계적 성질은 흉내 내지 못한다.
- 같은 사람이 계속 Jev 역할을 하면 "그 사람의 취향"을 플레이어가 학습한다. 세션마다 Jev 역할을 교대한다.
- 따라서 종이 결과는 **경험 구조(규칙·지름길·학습 곡선·좌절)**에 대한 증거이고, **Jev 판정 품질**에 대한 증거가 아니다.

### 1.6 경험 A/B(사람 Jev vs 손 표)
- 같은 참가자가 두 세션을 한다. 한 번은 사람 Jev, 한 번은 손 표다. 순서는 참가자마다 교차한다.
- 손 표 진행자는 각 명세 7.1의 표(인쇄된 조회표)로 판정하고, 같은 쪽지 형식으로 같은 자리에서 낸다. 판정 시간도 비슷하게 맞춘다(손 표가 빠르면 10초 기다림).
- 참가자에게는 "버전 1 / 버전 2"로만 알린다.
- 해석 주의: 사람 Jev는 실제 Jev보다 유리하다. 따라서 **사람 Jev도 손 표와 차이가 없다면** 실제 Jev에서도 차이가 없을 가능성이 높다는 신호로 쓴다(한 방향 추론만 허용).

### 1.7 공통 관찰 지표와 기록지
**판정 기록지**(판정 1회 = 1행)

| 시각 | 판정자 | 입력 요약 | 플레이어 사전 예측(말로) | 실제 결과 | 확신 | 요인 | 놀람/납득 체크(예상함 / 놀랐지만 납득 / 납득 안 됨) | 오류 주입 여부 |
|---|---|---|---|---|---|---|---|---|

**세션 요약지**
- 승패, 소요 시간, 판정 횟수
- 기억나는 사건 3개(세션 직후 질문, C의 Q7)
- "한 판 더 하겠는가" 1~5
- 지름길·반복 전략 관찰(진행자 메모)
- 3판째면 이전 판 대비 전략 변화(Q6)
- A/B 세션이면 블라인드 질문: "어느 버전의 세계가 더 살아 있었나 / 더 억울했나 / 다시 하고 싶은 쪽은"

## 2. N1 하루 되감기 키트 (SPEC-N1-v02 + ENGINE v02 보정)

### 2.1 구성물
- 큰 타임라인 표 2장(인물 6 × 시간대 8, 나란히 비교용), 연필 2색
- 장소 카드 6, 인물 카드 6(프로필 3문장, 계획 8칸, 고집, 고정 일정 2칸 표시, 행동 목록 6)
- 마을 물건 카드 18(주인 있는 물건 ≤ 6, 주인 표기), 플레이어 물건 카드 3, 전갈 카드 6
- 개입 예약지(루프당 3칸), 잠금 토큰 1, 기억 흘리기 토큰 1
- 인물별 "오늘 기록" 메모지(6칸, 출처 칸: 직접/전언/전갈)
- 기본 하루 기록지(사전 작성, 확신 포함), 장면 카드 메모지

### 2.2 사전 준비(30분, 세션 전)
- Jev 역할이 기본 하루 36판정을 미리 내고 기록지를 만든다(L0 흉내).
- 디자이너가 의도 해법 2개를 사람 Jev로 확인한다. 실제 출시에서는 실제 Jev로 확인한다.

### 2.3 진행(50분)
1. 규칙 설명 5분. 목표 장면: "T6 제과점에서 토마 '가게에서 반죽' + 이네스 '제과점에 들른다', 화재 없음".
2. 루프 1(관찰, 5분): 기본 하루를 장면 카드로 읽어 준다. 망설임 칸을 표시한다.
3. 루프 2~6(각 6~8분): 개입 예약 → 진행자가 T1부터 적용 → 탄성 검사 → 입력이 바뀐 인물만 Jev 역할 판정 → 고집 → 만남 기록(기본과 다른 사실·주인 물건만) → 장면 카드 → 바뀐 칸 색칠·요인 화살표.
4. 종료·회고 5분.

### 2.4 규칙 요점(진행자 카드)
- 잠금 루프당 1회, 고정 일정 장소·시간 잠금 불가.
- 기억 흘리기: 루프당 1회, **지난 루프 그 인물의 "직접" 기록만**.
- 탄성: 일탈한 인물에게 다음 시간대 새 기록이 없으면 Jev 없이 계획대로.
- 고집: 망설임이면 고집 중·상은 계획대로, 고집 상은 보통도 계획대로.

### 2.5 후보 고유 관찰 지표
- 루프별 바뀐 칸 수(발산 확인, 목표 중앙값 3~10)
- 지름길 시도와 성공: 잠금, 전갈로 두 인물 모으기, 기억 흘리기 직행
- "이상한 실험" 시도 수(손 표 조회표에서 0인 칸의 개입)
- 루프 4에서 인과를 말로 설명할 수 있는가(예/부분/아니오)

## 3. N3 세대선의 징조 키트 (SPEC-N3-v01)

### 3.1 구성물
- 배 단면도(구역 8, 문 6), 공동체 말 3
- 공동체 카드 3(성향 3문장, 교리 칸 8, 상처 칸 3, 적대 칸)
- **공동체별 교리 목록을 나란히 놓는 판**(A의 경험 요소 5)
- 징조 카드 8종, 에너지 토큰, 제사장 관찰 토큰 4
- 위기 막대 2(단계 0~3), 상황 기록 메모지(공동체별 4줄, 템플릿 20종 카드)
- 해석 표(7종과 행동 매핑), 기도 듣기 표(바람 규칙표)

### 3.2 진행(45분)
1. 설명 5분. **징조의 뜻은 알려 주지 않는다**(경험 요소 1: 어휘 0에서 시작). "처음 보내는 징조는 그 공동체의 교리가 된다"는 사실만 알린다.
2. 평온기 턴 1~5(10분), 위기 턴 6~(25분): 위기 진행 → 상황 기록 → 기도 듣기(진행자가 바람 1위만 말함) → 관찰(선택) → 징조 → 교리 있으면 규칙, 없으면 Jev 역할 → 교리 기록 → **행동을 말로 움직여 보여 주기**(경험 요소 4: 공동체 말을 실제로 옮기고, "제물을 바친다" 같은 장면을 읽어 준다).
3. 회고 5분.

### 3.3 규칙 요점
- 망설임 = 우연(교리 없음).
- 흔들림: 교리대로 했다가 2턴 안에 피해를 입으면 다음 같은 징조 때 재판정. "확고"로 다른 답일 때만 교리를 바꾼다.
- 관찰 토큰은 "첫 사용" 해석만 미리 본다. 기도 듣기는 해석을 알려 주지 않는다(경험 요소 2).
- 위기 단계 1·2는 통로 폐쇄 등 상태 변화이고, 단계 3이면 패배.

### 3.4 후보 고유 관찰 지표
- 판 끝에 플레이어가 말로 재구성한 "이 판의 신호 체계"(교리 수, 정확도)
- "통했다" 발화와 "왜 그렇게 읽었지" 발화의 비율
- 패배 원인 회고("해석 탓" vs "내 판단 탓")
- 오해된 교리를 나중에 이용한 사례 수(경험 요소 3)
- 공동체 간 교리 차이를 비교한 발화(경험 요소 5)
- 위기 시한 두 조건(6턴 / 8턴마다 단계 상승) 비교 세션

## 4. A03+ 세 판정관 키트 (SPEC-A03-v02)

### 4.2 진행(45분)
1. 설명 5분.
2. 6주기(각 5~6분): 경쟁자 사건(합의 가능) → 예비 심리 → 상정 + 주목 사실 → 판정관별 쪽지(5구간 단어 3개 + 요인) → 진행자 c_j·S 계산 → 플레이어에게는 기울기와 S 위치만 공개 → 판례 기록 → 집행(주민·판정관) → 의견 이력 → 대기 압박 → 새 주민 줄 서기.
3. 최종 심리, 회고 5분.

### 4.3 후보 고유 관찰 지표
- 주기마다 판정관별 투표 예측 정확도(3판 추이)
- "이 판례가 나중에" 같은 장기 계획 발화 수
- 상정 이유가 "누구 사정을 먼저 들을지"로 표현된 비율(A의 E1)
- 합의 사용과 그 이유
- 판례 그래프 회고: 최종 사건을 움직인 판례 설명이 몇 단계인가(직접 1단계 / 사다리 2단계 이상)

## 5. A01+ 소문이 도는 건물 키트 (SPEC-A01-v02)

### 5.1 구성물
- 방 카드 8(연결선), 경비원 카드 4(페르소나, 순찰, 의심 칸, 기억 칸 5), 인상 카드 4
- 물건 카드 16(범주 태그·범주 경로 표기), 행동 카드 6, 대답 토큰 3, 관찰 토큰 12
- 행동 패턴 표시판(진행자 계산), 무전망 그림, 소문 포스트잇, 경계 단계 판

### 5.2 진행(60분)
1. 설명 8분.
2. 30턴(약 45분, 턴당 1.5분 목표): 소문 도착 + J3 재전달(Jev 역할이 전달 수준을 고름) → 계획(관찰) → 이동 + 상호작용 → 행동 패턴 → **들어선 방에서 즉시 판정·실행** → 직접 목격 기록 → 순찰 이동과 새 조우.
3. 회고 7분.

### 5.3 후보 고유 관찰 지표
- 무전 보고 직후 보고 요소를 버린 비율, 그 뒤 범주·패턴 소문으로 다시 걸린 횟수
- 소문이 바뀌어 전해진 것을 알아챈 발화
- 인상 카드를 근거로 한 계획 발화
- 대답 4종 사용 분포, 이름 대기 성공
- 턴당 소요 시간(즉시 반응으로 템포가 무거워지는지)

## 6. 결과 정리와 판정(종이)
- 세션마다 기록지 2종(판정 기록지, 세션 요약지)을 모은다.
- 후보별 종이 판정(가설 기준, 실측과 별개)
  - **지름길**: 3세션 중 2세션 이상에서 같은 지름길로 승리 → 규칙 수정 필요(P1, 종이로 확정 가능).
  - **좌절**(N3 중심): 패배 회고의 과반이 "해석 탓" → 0장 대응 재검토.
  - **학습**: 3판째 예측 정확도가 1판째보다 +15%p 이상 → 통과 신호.
  - **A/B**: 사람 Jev 버전에서 "놀랐지만 납득" 비율과 블라인드 선호가 손 표보다 뚜렷이 높지 않으면, 실제 Jev에서도 차이가 작을 가능성 신호.
- 보고: 후보별 1쪽(지표, 관찰된 지름길, 규칙 수정 제안, 실측과의 교차 확인 항목).
