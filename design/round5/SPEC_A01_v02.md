## 1. 보존할 핵심 경험
1. **그럴듯해지기**: 숨지 않고, 들어서는 순간의 겉모습·행동으로 경비원의 상식을 통과한다.
2. **내 흔적이 나보다 먼저 간다 — 그리고 전해질수록 모양이 바뀐다**: "형광 조끼"가 "작업자 차림"이 되고 "서두르는 사람"이 된다. 소문의 모양은 누가 전했는지에 달려 있다.

## 2. 설계 목표 (v01 대비 변경만)
- 즉시 반응: 판정과 실행 사이에 플레이어가 끼어들 틈을 없앤다(치고 빠지기 차단).
- 계획 정보: 인상 카드(무료, 성향) + 관찰 토큰(유료, 지금의 판정)의 2단 구조.
- 원칙 2 근거를 J3, 의미 연관, 페르소나 × 기억 세 지점으로 좁히고 측정을 거기에 집중한다.

## 3. 핵심 루프
```
[계획] 지도, 인상 카드, 소문 지도(도착 예정), 관찰(선택) 확인
  ↓
[행동] 이동 1 + 상호작용 1
  ↓
[즉시 반응] 도착한 방의 경비원 전원 판정(J1) → 반응 즉시 실행(말을 검 → 대답 → J2, 신분 확인 → 제시 또는 도주)
  ↓
[세계 진행] 경비원 순찰 이동 → 이동으로 플레이어와 같은 방이 된 경비원도 J1 판정·즉시 실행 → 소문 도착·재전달(J3)
  ↓
(승리: 목표물 + 출구 / 패배: 체포, 경보 2회, 30턴)
```

## 4. 상태와 행동

### 4.1 상태(v01과 같고 아래만 추가·변경)
| 상태 | 변경 |
|---|---|
| 장면 요소 | 옷 / 손 / 행동 / 동행 + **행동 패턴**(규칙 계산, 버릴 수 없음) |
| 물건 | 각 물건에 범주 태그 1~2개(음식, 청소, 작업, 권위, 방문, 기술 등 8종)와 상위 범주 경로(예: 형광 조끼 → 작업자 차림 → 외부 업체 사람) |
| 경비원 기억 | 항목 = (출처: 직접|무전(전한 사람), 경과, 구역, 소문 단위). 소문 단위 = {원래 요소 | 상위 범주 | 행동 패턴} 중 하나의 문장 |
| 좋은 인상 | J2 결과가 "납득"이면 그 경비원 기억에 "{구역}에서 {범주} 차림의 사람과 이야기했다, 괜찮았다"(직접) 추가 |

### 4.2 행동 패턴(규칙 계산, 장면 5번째 요소)
매 턴 아래 중 하나(우선순위 순)가 플레이어의 현재 행동 패턴이 된다.
1. "같은 복도를 다시 지나감": 최근 6턴 안에 같은 방을 2회 이상 방문.
2. "서두름": 2턴 연속 이동.
3. "혼자 오래 머묾": 같은 방에서 2턴 이상 이동 없이 무리 동행 없음.
4. "무리에 섞여 있음": 동행이 무리.
5. 없음.
- 패턴은 물건처럼 버릴 수 없다. 움직임을 바꿔야 바뀐다.

### 4.3 대답(말을 검 직후, 판당 3회)
| 대답 | 조건 | J2 입력에 들어가는 것 |
|---|---|---|
| 손에 든 물건을 보여 준다 | 손 슬롯에 물건 | 물건 설명 |
| 가방의 물건을 꺼낸다 | 가방에 물건 | 물건 설명(출입증 포함) |
| 이 방의 무언가를 가리킨다 | 방에 물건·장비·무리 | 그 대상 설명 |
| 아까 만난 경비원 이름을 댄다 | 그 경비원 기억에 플레이어의 좋은 인상이 있음 | "{이름}이 보내서 왔다" + 그 경비원 기억의 좋은 인상 문장 |

### 4.4 신분 확인 즉시 처리
- 출입증(구역 일치)을 제시하면 통과한다. 경비원 기억에 "출입증 확인함"이 추가된다.
- 출입증이 없으면 **도주**만 가능하다. 인접 방으로 이동하고, 경보 +1, 그 경비원이 2턴 추적한다(세계 진행 단계에 같은 방이 되면 체포).
- 도주하지 않으면 체포된다.

### 4.5 인상 카드(무료)
- 경비원마다 2문장: "관대함: {범주}", "예민함: {범주}". 개발 시 사전 계산 표(기억 없음)에서 범주별 평균 엄격도가 가장 낮은·높은 범주를 뽑아 만든다.
- 확률이나 결과를 약속하지 않으므로 표시 = 실제 규칙에 걸리지 않는다. 소문이 쌓이면 실제 반응이 인상 카드와 달라질 수 있고, 그것이 정보가 된다.

## 5. Jev 판정 명세 (ENGINE 스키마 "A01")

### 5.1 J1 경비원 반응 (ACT)
- 입력(ENGINE 2.2 형식)

  - log: 기억 5칸(4.1 형식)
- 질문: J1a(ACT) "이 경비원은 지금 들어선 이 사람에게 무엇을 하는가?" 자기 일 계속 / 눈여겨봄 / 말을 검 / 신분 확인 / 무전 보고. J1b "무전으로 보고한다면 무엇을 가장 먼저 말하겠는가?" 옷 / 손 / 행동 / 동행 / 행동 패턴. J1c(FACTOR).

### 5.2 J2 대답 판정 (ACT)

- 선택지: 납득하고 보냄 / 눈여겨봄(의심 +1) / 신분 확인.

### 5.3 J3 소문 재전달 판정 (ACT, A 제안 수용)
- 발동: 소문이 경비원 X에게 도착한 턴의 세계 진행 단계. X가 무전망의 다음 경비원에게 전할 때 1회.
- 입력: X의 페르소나 + 받은 소문 문장 + X의 기억 + 소문 원래 요소의 범주 경로(선택지 문장).
- 질문: "{X}는 다음 사람에게 이 소문을 무엇이라고 전하는가?"
- 선택지: 원래 요소 그대로 / 상위 범주 1단계 / 상위 범주 2단계 / 행동 패턴 / 전하지 않음.
  - 범주 경로는 물건마다 디자이너가 고정한다. 닫힌 선택지다.
- 결과: 다음 경비원 기억에는 고른 수준의 문장으로 들어간다. "전하지 않음"이면 전파가 멈춘다.
- 원칙 2 근거의 중심이다. 전직 주방장은 음식 범주로, 신입은 "체크리스트에 없는 사람"(행동 패턴)으로 전한다는 가설을 측정한다.

### 5.4 직접 목격 기억 생성 (규칙, C4-A01-3)
- J1a 결과가 눈여겨봄 이상이면, J1c가 고른 요소(요소가 아니면 J1b 요소) 1개를 "직접 봄" 기억으로 추가한다.
- 기록은 그 턴의 모든 판정이 끝난 **뒤**에 붙는다. 같은 턴의 관찰과 확정 판정은 같은 입력을 쓴다.

### 5.5 캐시·사전 계산·대체
- 캐시 키: ENGINE 3.1. 스키마 필드는 5.1과 같다.
- 사전 계산(L0): 기억 없음 × 의심 0 × 경계 0 조합(경비원 × 구역 × 시간대 × 겉모습 × 행동 패턴 5). 인상 카드 생성에도 쓴다.
- 대체 함수: 7.1의 가장 강한 손 표. 결과는 L2에만 기록한다.

## 6. 규칙과 종료 조건

### 6.1 턴 순서(확정)
1. 소문 도착 처리 + J3 재전달(같은 턴 요청에 묶음).
2. 경계 단계 갱신(10, 20턴 시작).
3. 계획: 관찰 사용 가능(관찰 결과는 L2 사본 + L1).
4. 플레이어 행동: 이동 → 상호작용.
5. 행동 패턴 계산.
6. **즉시 반응**: 플레이어가 있는 방의 경비원 전원 J1 → 결과 실행.
   - 말을 검 → 대답(선택) → J2. 대답하지 않거나 대답이 없으면 신분 확인으로 간주한다.
   - 신분 확인 → 4.4.
   - 무전 보고 → 소문 생성(J1b 요소, 장면 단위 문장).
   - 눈여겨봄 → 의심 +1.
7. 직접 목격 기억 기록(5.4).
8. 세계 진행: 경비원 순찰 이동. 추적 중인 경비원은 플레이어 방으로. 플레이어 방에 새로 들어온 경비원은 J1 → 즉시 실행.
9. 턴 +1.

### 6.2 관찰 = 실제
- 관찰은 "이번 턴에 이 방에 이 장면으로 들어가면 경비원 X는?"을 묻는다. 소문 도착은 1단계에서 끝났으므로, 같은 턴에 같은 장면을 만들면 6단계 판정은 캐시 적중으로 같은 결과다. 행동 패턴도 관찰 시점에 그 행동을 가정해 계산한다.

### 6.3 승리·패배
- v01과 같다. 체포, 경보 2회, 30턴 초과는 패배다.

### 6.4 표현 규칙(망설임)
- 결과가 망설임 규칙으로 정해지면, 경비원이 한 번 돌아보는 연출과 의심 칸 깜빡임을 보여 준다(A의 E4).

## 7. 원칙 2 경험 테스트

### 7.1 가장 강한 손 표(대체 함수 겸용, 측정 전 고정)
- 기본: L0 사전 계산 표. 공정 비교를 위해 Jev 버전과 동일하다.
- 기억 보정(엄격도 단계 이동):
  - 기억 항목이 장면 요소와 원래 요소 일치: +2
  - 범주 태그 일치: +1
  - 행동 패턴 일치: +1
  - 무전 기억은 직접 기억의 절반(내림)
- 페르소나: 경비원마다 민감 범주 2개(+1), 관대 범주 2개(−1). 인상 카드와 같은 데이터.
- 소문 재전달: 경비원마다 고정 일반화 성향 1개(그대로 / 범주 1단계 / 범주 2단계 / 행동 패턴). 디자이너가 페르소나를 보고 지정한다.
- 좋은 인상: 범주 일치 좋은 인상 1개당 −1. "이름 대기" 대답은 좋은 인상이 있으면 납득.

### 7.2 Jev만의 차이가 생길 것으로 예상하는 지점(가설)
1. **J3의 상황 의존 일반화**: 같은 경비원이라도 기억 내용에 따라 다른 수준으로 전한다(손 표는 경비원당 고정 1개).
2. **범주 밖 의미 연관**: "케이터링은 15시에 끝났다" 기억 ↔ "커피 쟁반"(범주: 방문). 손 표 범주가 다르면 손 표는 반응하지 않는다.
3. **페르소나 × 기억 반전**: 같은 소문을 들어도 관대해지는 방향(전직 주방장이 주방 쪽 행동에 대해).
- 7.2에서 뺀 것: 전파 경로·지연(결정론), 정확 일치(H2와 손 표가 같게 처리).

## 8. 대표 플레이 예시 (v02 규칙)
1. 턴 4, 작업동 복도. 인상 카드: 세라 "관대함: 기술 / 예민함: 작업". 겉모습 형광 조끼(작업) / 케이블(기술) / 급히 걷는다 / 없음, 패턴 "서두름". 들어서자 즉시 J1(세라): **무전 보고**, J1b = 옷. 소문 "작업동에서 형광 조끼를 입고 서두르던 사람"이 생성된다. 직접 목격 기억도 기록된다.
2. 턴 5 시작. 소문이 오도(지연 1)에게 도착한다. J3(오도, 전직 주방장): **행동 패턴**으로 결정 → 한에게 "서두르는 사람이 돌아다닌다"가 전해질 예정이다(2턴 뒤).
3. 플레이어는 조끼를 버렸다. 그러나 오도의 기억에는 원래 요소, 한에게 갈 소문에는 "서두르는 사람"이 남는다. 패턴을 지우려면 2턴 연속 이동을 멈춰야 한다. 탕비실에서 한 턴 머물며 "커피 쟁반"을 줍는다(패턴: 혼자 오래 머묾).
4. 턴 7, 로비. 한 앞으로 쟁반을 들고 천천히 들어간다. 관찰은 쓰지 않았다(인상 카드: 한 "관대함: 방문"). 즉시 J1(한, 기억: 무전 "서두르는 사람"): **자기 일 계속**(망설임) → 의심 +1, 한이 돌아보는 연출.
5. 같은 차림으로 서두르면 한은 엄해진다. 출구는 한의 로비다.

## 12. 종이 프로토타입 규칙 요약 (1쪽, v02)

**준비물**: v01 + 물건 카드에 범주 태그·범주 경로 표기, 인상 카드 4장, 행동 패턴 표시판, 대답 토큰 3.

**역할**: 플레이어, 진행자(규칙·소문 이동·행동 패턴 계산), Jev 역할 1명.

**Jev 역할 규칙**(Q19)
1. 경비원 카드, 장면 5요소, 기억 칸만 본다(칸막이). 출력은 반응 + 확신(확고/보통/망설임) + 가장 영향 준 것. 설명은 금지한다.
2. 소문 재전달(J3) 때는 "이 경비원이 다음 사람에게 무엇이라고 전하나"를 범주 경로 카드의 선택지 중에서 고른다.
3. 같은 입력이면 기록지대로 같은 답을 한다. 오류 주입은 주사위 6.

**턴 진행**: 소문 도착 + 재전달 → 계획(관찰) → 이동 + 상호작용 → 행동 패턴 → **들어선 방에서 즉시 판정·실행**(말을 검 → 대답 → 재판정, 신분 확인 → 출입증 또는 도주) → 직접 목격 기록 → 경비원 순찰 이동(새 조우는 즉시 판정).

**하드 규칙**: H1~H3, 망설임 = 덜 엄격 + 의심 +1.

**기록할 것**: 무전 보고 직후 행동(버렸나), 버린 뒤 다시 걸렸나, 소문이 바뀌어 전해진 것을 알아챘나, 인상 카드 사용 발화.

**손 표 버전**: 진행자가 7.1 표로 판정한다(블라인드).
