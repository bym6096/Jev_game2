# 라운드 11 아이디어 28개 (요약)

| 가제 | 한 줄 설명 |
|---|---|
| 위장 단어 | 친구들과 숨바꼭질. 몸 대신 "먼지 쌓인 옷걸이"처럼 이름으로 숨고, 괴물은 그 물건이 그 방에 어울리는지 본다 |
| 흉내 소리 | 눈먼 괴물에게서 도망. 내 발소리를 "물방울 소리"처럼 글로 적어 속인다 |
| 감청 무전 | 둘이 협동. 지도 본 쪽이 친구를 안내하는데 괴물도 무전을 엿듣는다. 둘만 아는 암호를 만든다 |
| 동사 덱 | 카드 게임. 카드는 "녹이다·칭찬하다", 적은 "웨딩 케이크". 그 동사가 그 적에 얼마나 먹히는지가 피해 |
| 연상 포커 | 포커처럼 낱말 다섯 장을 낸다. "상어-치과-돈-공포-월요일"이 연상으로 이어지면 스트레이트 |
| 미끼 | 낚시. 바늘에 아무 낱말이나 단다. 물고기마다 입맛이 다르다 |
| 낱말 자석 | 병 속에 낱말을 떨어뜨리면 뜻이 가까운 것끼리 붙고 먼 것은 밀어낸다 |
| 말이 발판 | 점프 게임. 낭떠러지에서 "구름"을 치면 발판이 생기는데, 얼마나 단단할지는 모른다 |
| 맥가이버 배낭 | 생존. 곰이 나오면 가방 속 프라이팬을 어떻게 쓸지 짧게 적는다 |
| 1923년 파티 | 친구들끼리 정체 숨기기. 미래에서 온 사람이 무심코 요즘 말을 하면 파티장이 깨진다 |
| 가짜 명찰 | 잠입. 명찰에 직함을 적어 경비원을 속인다 |
| 그림자 극장 | 도형을 겹쳐 손 그림자를 만든다. 관객이 그걸 무엇으로 보는지가 극을 움직인다 |
| 잡식 괴물 | 키우기. 무엇을 먹였는지에 따라 다른 모습으로 진화한다 |
| 추상 잡화점 | 가게 운영. "약간 낡은 변명", "5분짜리 침묵"에 값을 매겨 손님에게 판다 |
| 이름 경마 | 친구들과 경마 내기. 말 이름이 코스(늪, 귀신 길)에서의 속도를 정한다 |
| 골든 레코드 | 우주 외교. 인류 대표 물건 다섯 개를 보내면 외계인마다 다르게 오해한다 |
| 버릇 읽는 딜러 | 카드 심리전. 딜러는 내 패가 아니라 내가 망설인 시간과 버릇을 읽는다 |
| 끄덕임 면접 | 리듬 코미디. 말 없이 끄덕임·웃음·침묵만으로 면접을 통과한다 |
| 동시통역 | 리듬 게임. 쏟아지는 말 조각을 박자에 맞춰 받아 통역문을 만든다. 놓치면 외교 사고 |
| 분위기 동네 | 아늑한 도시 짓기. 장례식장 옆 놀이공원처럼 놓은 건물들이 동네 성격을 만든다 |
| 괴담 방어선 | 타워 디펜스. 도시 괴담을 물건으로 막으면, 다음 밤 괴담이 그걸 극복해서 돌아온다 |
| 묘비명 | 죽을 때 묘비명을 직접 쓰면, 다음 판에 그 묘비명이 던전과 보스가 된다 |
| 형용사 소코반 | 상자 밀기 퍼즐. "무거운"을 풍선에 붙이면 무슨 일이 생길까 |
| 무한 가위바위보 | 1대1. 동시에 낱말 하나씩 낸다. "바다" 대 "스펀지", 누가 이기나 |
| 인과 도미노 | 사건 카드를 줄 세워 나비 날갯짓에서 대통령 재채기까지 넘어뜨린다 |
| 새치기 | 콘서트 줄 앞 37명. 한 사람씩 핑계를 대며 앞으로 간다 |
| 조작 퀴즈쇼 | 퀴즈쇼 작가가 되어 스폰서 조카만 맞힐 문제를 쓴다 |
| 가족사진 | 셔터까지 10초. 사이 나쁜 친척들을 잘 배치해 모두 웃게 만든다 |

## 작가가 가장 해 보고 싶은 5개
1. **위장 단어**: 요즘 인기 숨바꼭질 게임 틀이라 한눈에 이해되고, 웃긴 장면이 저절로 나온다.
2. **감청 무전**: 친구와 즉석 암호를 만드는 재미. 판정이 친구 둘 사이의 대화에 끼어드는 첫 시도.
3. **버릇 읽는 딜러**: 상대가 내 글이 아니라 내 행동 습관을 읽는다. 일부러 버릇을 꾸미는 심리전.
4. **연상 포커**: 유명 카드 게임 틀이라 설명이 필요 없고, "이게 된다고?" 순간에 점수가 터진다.
5. **낱말 자석**: 뜻이 곧 힘이 되는 장난감. 화면이 계속 움직여 보는 맛이 있다.

고르기는 다음 단계 검토자가 한다. 위 5개는 참고용이다.
