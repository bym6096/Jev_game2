# SPEC A01+ 소문이 도는 건물 — 플레이테스트 가능한 최소 규칙 명세

## 1. 선정 아이디어와 보존할 핵심 경험

- 아이디어: A01+ (A-ALT-v01). 기반 패턴: B-P06(공개 의도 판정자), B-P05(분류 경계 밀기), B-P07(전파망).
- **보존할 핵심 경험 2가지**
  1. **"그럴듯해지기"**: 숨지 않는다. 지금 손에 든 것, 입은 것, 하는 행동으로 경비원의 상식을 통과한다.
  2. **"내 흔적이 나보다 먼저 간다"**: 한 번 들킨 특징은 무전을 타고 소문이 되어 앞쪽 경비원에게 먼저 닿는다. 플레이어는 소문의 도착 시점을 보고, 소문보다 빨리 움직이거나, 겉모습을 바꾸거나, 소문을 일부러 엉뚱한 특징으로 오염시킨다.

## 2. 설계 목표와 명시적 가정

| 목표 | 이를 위한 규칙 결정 |
|---|---|
| 플레이어의 주 행동은 맥락 조작이다(C의 Q4) | 행동 = 이동, 물건 줍기·버리기, 행동 카드 바꾸기, 무전 중계기 조작. 플레이어가 글을 쓰거나 답을 제출하는 행동은 없다. |
| 판정자는 이름 있는 경비원 6명이다(Q3, Q8) | 경비원마다 페르소나 문장 3개와 판 중 쌓이는 기억 5칸이 있다. |
| 확률은 미리 보이고, 표시 = 실제(R2) | 결과는 K2(1위 확정)이며 주사위가 없다. 관찰 토큰으로 본 결과는 캐시되어 실제 판정과 같다. |
| 시야 계산 비중을 줄인다(C-A01-3) | 그리드·시야선이 없다. 방(노드) 단위로, 같은 방에 있으면 서로 본다. 방은 대부분 열린 공간이다. |
| 경로 미리보기 폭증 방지(C-A01-2) | 판정 입력은 경로가 아니라 이산화된 "장면"이다. 미리보기는 판당 12개인 관찰 토큰으로만 가능하다. |
| 만능 변장 방지(C-A01-1) | 기억과 정확히 일치하는 요소는 게임 규칙으로 하한을 강제하고, 의미 연관은 Jev가 판단한다. |
| 비용 확정 | 판당 실시간 요청 상한은 60이다. 상한은 게임 규칙(턴 수, 관찰 토큰, 대답 횟수)으로 강제된다. |

## 3. 핵심 루프

```
[턴 시작] 소문 도착 처리 → 경비원 의도 표시(지난 판정 결과)
   ↓
[계획] 지도·소문 도착 예정·의도를 보고 다음 행동 결정 (선택: 관찰 토큰으로 가상 장면 판정 보기)
   ↓
[행동] 이동 1칸(인접 방) + 상호작용 1개
   ↓
[경비원 실행] 표시된 의도대로 경비원 행동(다가옴, 신분 확인, 무전 보고 → 소문 생성)
   ↓
[판정] 플레이어와 같은 방에 있는 경비원 전원을 한 요청으로 판정 → 다음 턴 의도 확정·표시
   ↓
(목표물 회수 후 출구 도달 = 승리 / 체포 = 패배 / 턴 30 초과 = 패배)
```

- **목표**: 보안 구역의 목표물(물건 1개)을 주워 출구 방에 도달한다.
- **행동**: 4장에 정의.
- **제약**: 30턴, 관찰 토큰 12개, 겉모습 슬롯 4개, 경계 단계.
- **정보**: 경비원 의도와 마진, 무전망과 소문 도착 예정, 경비원 기억(직접 확인 가능), 요인 하이라이트.
- **보상**: 진행(목표 접근), 정보(소문 상태), 새 물건.
- **실패**: 체포(6.3절). 의심·경계 상승은 실패가 아니라 압박이다.

## 4. 게임 상태와 행동

### 4.1 게임 상태

| 상태 | 형식 | 비고 |

| 방 속성 | 구역, 방 종류 태그(로비/탕비실/서버실 등), 물건 목록 | 물건은 방에 놓인 위치 없이 목록으로 둔다 |
| 경비원 6명 | id, 페르소나(고정 3문장), 현재 방, 순찰 경로(공개, 4~6방 순환), 의심 카운터(0~2), 기억 5칸, 현재 의도 | |
| 무전망 | 경비원 간 간선 + 지연(1~3턴) + 중계기(방에 위치, 켜짐/꺼짐) | 중계기가 꺼지면 그 중계기를 거치는 간선이 끊긴다 |
| 소문 대기열 | (요소 태그, 출처 경비원, 목격 구역, 생성 턴, 수신 경비원, 도착 턴) | 지도에 아이콘과 남은 턴으로 표시 |
| 플레이어 | 현재 방, 겉모습 4슬롯, 소지 가방 2칸(겉모습에 안 보이는 보관), 관찰 토큰, 대답 카드 3장 | |
| 겉모습 슬롯 | 옷 / 손에 든 것 / 행동 / 동행 | 동행 = 없음 또는 같은 방의 NPC 무리(관람객·작업자 무리, 순찰하는 NPC) |
| 경계 단계 | 0~3 | 10턴마다 +1, 경보 발생 시 +1. 판정 입력에 들어간다. |

| 행동 | 효과 | 비용 |
|---|---|---|
| 이동 | 인접 방으로 이동. 잠긴 문은 해당 열쇠·출입증이 있어야 한다. | 이동 1 |
| 줍기 | 방의 물건 1개를 손 슬롯 또는 가방으로 | 상호작용 1 |
| 입기·벗기 | 옷 슬롯 교체(방에 있는 옷 물건) | 상호작용 1 |
| 버리기 | 슬롯·가방의 물건을 현재 방에 놓기 | 상호작용 1 |
| 행동 카드 바꾸기 | 행동 슬롯을 카드 8장 중 하나로(일부는 특정 물건이 필요, 예: "바닥을 닦는다" ← 대걸레) | 상호작용 1 |
| 무리에 붙기·떨어지기 | 같은 방의 NPC 무리를 동행으로. 무리는 자기 경로로 움직이며, 붙어 있으면 이동 행동 대신 무리를 따라간다. | 상호작용 1 |

| 관찰 | 관찰 토큰 1을 써서, 같은 방이나 인접 방 경비원 1명에 대해 "내가 다음에 만들 장면"의 판정을 미리 본다. | 토큰 1, 행동 아님 |

## 5. Jev 판정 명세

### 5.0 공통

- 모든 판정의 입력은 아래 템플릿으로 직렬화한다. 목록 필드는 사전 순으로 정렬하고 수치는 지정 구간으로 반올림한다(R6).
- **캐시**: 정규화된 입력 전체 + 질문 ID의 해시가 같으면 같은 결과를 쓴다. **판 간 전역 캐시**를 쓴다(C-X03의 R6 지적 수용). 입력에 그 판의 기억이 들어가므로, 전역 캐시가 맞는 경우는 사실상 기억이 비어 있는 판정뿐이다. 그 판정은 원래 사전 계산 대상이다.
- **확률 구간**: 원시 확률은 화면에 내지 않는다. 결과는 K2(1위)로 정하고, 마진(1위 − 2위)을 3단계로 표시한다. 확고 ≥ 0.30, 보통 0.10~0.30, 망설임 < 0.10. 경계값은 실측 분포의 분위수(하위 25%, 상위 50%)로 다시 정한다(C-R16 수용).
- **동점·망설임 규칙**(C-X03의 R2 지적 수용): 마진이 "망설임"이면 1위·2위 중 **덜 엄격한 쪽**을 결과로 하고 의심 +1을 준다. 엄격도 순서는 자기 일 < 눈여겨봄 < 말을 검 < 무전 보고 < 신분 확인. 플레이어는 "망설이는 경비원"을 볼 수 있고, 그 경비원이 다음에는 엄해진다는 것을 배운다.
- **하드 규칙**(C-R03 대응, Jev 호출 전 처리): 아래 경우는 Jev에 보내지 않는다.
  - H1: 보안 구역(Z3)에서 출입증 없이 "잠긴 것을 연다" 행동 → 신분 확인.
  - H2: 장면 요소 중 2개 이상이 그 경비원 기억의 요소와 **정확히 같은 태그** → 결과 하한이 "눈여겨봄"이 된다. Jev 결과가 "자기 일 계속"이면 "눈여겨봄"으로 올린다(C-A01-1 수용).
  - H3: 경계 단계 3에서 Z3에 있으면 → 결과 하한이 "말을 검".

### 5.1 J1 경비원 반응 판정 (주 판정, 실시간 또는 표)

**입력 상태 형식**(경비원 1명분, 한 요청에 경비원 여러 명분을 넣는다)

```
[경비원] {guard_id} / {페르소나 문장 3개(고정 텍스트)}
[근무] 구역={Z1|Z2|Z3}, 방종류={태그}, 시간대={오전|점심|오후|야간}, 경계단계={0..3}, 의심={0..2}
[보이는 사람]
  옷={물건태그}: {물건 설명 1문장(고정)}
  손={물건태그|없음}: {설명}
  행동={행동카드태그}: {설명}
  동행={없음|무리태그}: {설명}
[이 경비원의 기억] (최대 5개, 최근 순)
  - {최근|조금 전|오래 전}, {직접 봄|무전으로 들음(출처 경비원 이름)}: {구역}에서 {요소 설명}
```

- 시간대는 턴을 4구간으로 나눈 것(턴 1~8 오전 …). 기억의 경과는 3구간(≤3턴 최근, 4~10 조금 전, 11+ 오래 전)이다.

**질문 J1a**(choice): "이 경비원은 지금 보이는 사람에게 다음에 무엇을 하는가?"
- 선택지: 자기 일 계속 / 눈여겨봄 / 말을 검 / 신분 확인 / 무전 보고

**질문 J1b**(choice, 같은 요청): "이 경비원이 무전으로 보고한다면 무엇을 가장 먼저 말하겠는가?"
- 선택지: 옷 / 손 / 행동 / 동행 (각 슬롯의 현재 요소)
- J1a가 "무전 보고"일 때만 결과를 쓴다. 항상 같이 묻는 이유는 직렬 호출을 피하기 위해서다.

**질문 J1c**(choice, 같은 요청): "이 반응에 가장 큰 영향을 준 것은?"
- 선택지: 옷 / 손 / 행동 / 동행 / 기억1~5 중 존재하는 것 / 근무 상황
- 결과는 화면에서 해당 요소를 하이라이트한다(R4, C-R08). ▲▼ 변화량 표시는 쓰지 않는다(C-X03의 R3 반례 수용: 상호작용이 있으면 변화량 표시는 원인을 잘못 가르친다).

**확률 처리**: J1a는 K2 + 마진 3단계 + 망설임 규칙. J1b, J1c는 K2(1위만).

**캐시 키**: hash(J1, guard_id, 구역, 방종류, 시간대, 경계단계, 의심, 정렬된 4슬롯 태그, 기억 항목 목록[경과구간, 출처유형, 출처id, 구역, 요소태그]).

**사전 계산 vs 실시간**
- 사전 계산(개발 시 Jev로 생성): 기억이 비어 있는 모든 조합. 경비원 6 × 구역 3 × 시간대 4 × 경계 4 × 의심 3 × 겉모습 조합(옷 6 × 손 10 × 행동 8 × 동행 3 = 1,440) ≈ 1,240만 질문. 비용이 커서 전부 하지는 않는다. **의심·경계는 하드 규칙 처리 후 입력에서 빼고**(의심·경계를 넣은 판정은 실시간으로만) 경비원 × 구역 × 시간대 × 겉모습 ≈ 10.4만 질문만 사전 계산한다(가설 비용: 2k 토큰 기준 약 $9).
- 실시간: 기억이 1개 이상이거나 의심·경계가 0이 아닌 판정. 판의 중반 이후 판정 대부분이 여기에 속한다.

### 5.2 J2 대답 판정 (말을 검 이후, 실시간)

- 입력: J1 입력 + `[방금 일] 경비원이 말을 걸었고, 상대는 "{대답 카드 설명}"라고 했다.`
- 질문(choice): "이 경비원은 그 대답을 듣고 어떻게 하는가?" — 납득하고 보낸다 / 눈여겨본다(의심 +1) / 신분을 확인한다
- 대답 카드 3종(고정): "바쁘다며 지나간다", "위에서 지시받았다고 한다", "오히려 길을 묻는다".
- 확률 처리: K2 + 망설임 규칙. 직렬 깊이 2(J1 → J2). 턴당 J2는 최대 1회(한 턴에 말을 거는 경비원이 둘이면 플레이어가 한 명을 고르고, 다른 경비원은 규칙으로 "눈여겨봄").

### 5.3 소문 생성·전파 (규칙, Jev 아님)

- J1a = 무전 보고 → 소문 1개 생성: (J1b가 고른 요소 태그, 출처, 구역, 턴).
- 무전망 간선마다 지연 d(1~3턴) 뒤 이웃 경비원의 기억에 "무전으로 들음" 항목으로 추가된다. 받은 경비원은 1회 재전파한다(망 지름 이상으로는 퍼지지 않음).
- 기억 5칸이 차면 가장 오래된 항목이 밀려난다. 직접 목격 항목은 무전 항목보다 1턴 늦게 밀려난다(가중).
- v01은 변형 없이 전달한다. 변형 전달(B-P07)은 v02 후보다.

### 5.4 판당 호출 상한과 강제 방법

| 출처 | 상한 | 강제 방법 |
|---|---|---|
| J1 확정 판정 | 30 | 턴당 1요청(같은 방 경비원 묶음) × 30턴 |
| 관찰(J1 가상) | 12 | 관찰 토큰 12개 |
| J2 대답 | 3 | 대답 카드 3장 |
| 예비(재시도·타임아웃 재요청) | 15 | 요청 실패 시 1회 재시도 |
| **합계** | **60** | 턴 수·토큰·카드가 모두 게임 규칙이므로 정상 플레이에서 상한 초과가 없다 |

- 최악 비용(가설): 60 × 3k 토큰 × $0.042/M ≈ $0.008/판.
- 직렬 깊이: 턴당 최대 2(J1 → J2). 경비원 실행 애니메이션(약 1초) 동안 J1 요청을 보낸다.

### 5.5 응답 실패 시 대체

- 1.5초 안에 응답이 없거나 오류가 나면 1회 재시도하고, 그래도 실패하면 **대체 판정**을 쓴다.
  - 대체 판정 = 사전 계산 표(기억 없음) 결과 + "기억 일치 보정": 기억 요소와 정확히 같은 태그가 장면에 1개 있으면 엄격도 1단계 상승, 2개 이상이면 2단계(H2 포함).
  - 이 보정 규칙은 원칙 2 A/B 테스트의 "손 표" 버전과 같다(7장).
- 대체 판정도 캐시에 기록해 그 판 안의 일관성을 유지한다.
- 출시 UX에는 "추정" 표시를 하지 않는다(C-X03의 R13 지적 수용). 테스트 빌드에서만 표시하고 로그를 남긴다.

## 6. 규칙과 종료 조건

### 6.1 턴 순서(확정 규칙)
1. 소문 도착 처리(도착 턴이 된 소문을 수신 경비원 기억에 추가).
2. 경계 단계 갱신(10, 20턴 시작 시 +1).
3. 플레이어 계획 단계: 관찰 토큰 사용 가능. 관찰 결과는 캐시에 들어간다.
4. 플레이어 행동: 이동 → 상호작용 순서.
5. 경비원 실행: 지난 판정으로 표시된 의도를 실행한다. 신분 확인 의도의 경비원이 플레이어와 같은 방이면 6.3 체포 판정. 무전 보고는 소문을 생성한다.
6. 판정: 플레이어와 같은 방에 있는 경비원 전원의 J1(하드 규칙 → 캐시 → 표 → 실시간 순서로 조회). 말을 검 결과가 나오면 즉시 J2.
7. 의도 표시. 턴 +1.

### 6.2 관찰의 의미(표시 = 실제 보장)
- 관찰은 "내가 이번 턴에 이 방으로 가서 이 겉모습을 하면 경비원 X가 어떻게 하는가"를 묻는다. 그 가상 장면의 입력으로 J1을 실행해 캐시에 넣는다.
- 소문 도착은 턴 시작에만 일어나므로, 관찰 후 같은 턴에 정확히 그 장면을 만들면 확정 판정은 캐시 적중으로 같은 결과가 된다.
- 예외: 같은 턴에 다른 경비원이 같은 방으로 들어오면 그 경비원은 별도 판정한다. 관찰한 경비원의 결과는 그대로다.

### 6.3 체포와 탈출
- 신분 확인 의도의 경비원과 경비원 실행 단계에 같은 방에 있음 →
  - 그 구역에 맞는 출입증 물건을 슬롯이나 가방에 갖고 있으면 통과. 경비원 기억에 "출입증 확인함"이 추가된다.
  - 없으면 체포 → **패배**.
- 신분 확인 의도가 표시된 상태에서 플레이어가 방을 떠나면 경비원은 1턴 추적한다(인접 방으로 이동). 추적 끝에 같은 방이면 체포, 아니면 경보 → 경계 단계 +1, 모든 경비원 기억에 "수상한 자 도주(그때 겉모습 4요소 중 J1b 요소)" 추가.
- 경보 2회 → **패배**.

### 6.4 승리·패배
- 승리: 목표물을 슬롯이나 가방에 갖고 출구 방에 도달.
- 패배: 체포, 경보 2회, 30턴 초과.
- 판 평가(메타, v01은 기록만): 남은 턴, 생성된 소문 수, 사용 토큰.

## 7. 원칙 2 경험 테스트 (BRIEF v02 기준)

### 7.1 "손 표" 버전 정의
같은 판을 Jev 대신 아래 덧셈 표로 돌린다.
- 기본값: 사전 계산 표(기억 없음). 공정한 비교를 위해 기본 반응은 Jev 버전과 같게 둔다. 차이는 **그 판의 역사를 다루는 방식**에서만 나게 한다.
- 역사 처리: 기억 요소와 장면 요소의 태그가 정확히 같으면 1개당 엄격도 +1단계. 무전 기억은 직접 목격의 절반 효과(2개당 +1).
- 페르소나 처리: 경비원마다 "민감 태그" 2개(디자이너 지정)에 해당하는 요소가 장면에 있으면 +1단계.

### 7.2 체감 차이가 생길 것으로 예상하는 지점 (가설)
1. **의미 연관 기억**: "케이터링은 15시에 끝났다"는 무전이 "음식 상자"에는 반응을 일으키고 "청소 카트"에는 일으키지 않는다. 손 표는 태그가 다르면 반응하지 않는다.
2. **소문 오염 전략의 효과**: 일부러 "빨간 모자"를 보고하게 한 뒤 버리는 전략. 손 표에서는 단순히 무의미한 태그가 쌓이지만, Jev에서는 경비원이 "빨간 모자를 찾는 중"이라는 맥락 때문에 다른 요소에 덜 주의할 수 있다(가설, 미검증).
3. **페르소나 × 기억 상호작용**: 전직 주방장 경비원은 음식 관련 소문을 듣고도 주방 쪽 행동에는 관대하다. 손 표의 민감 태그로는 "관대해지는" 방향을 표현하기 어렵다.
4. 반대로 **차이가 없을 것으로 예상하는 지점**: 같은 옷을 또 본 경우(정확 일치). 손 표와 같아야 정상이며, H2 하드 규칙이 둘을 같게 만든다.

### 7.3 A/B 플레이테스트 설계
- **사전 측정(구현 전, C의 Q18)**: 경비원 6 × 장면 10 × 기억 조건 4(없음 / 정확 일치 1 / 의미 연관 1 / 무관 1) = 240 질문. 측정 항목: (a) 1위 확률 분포(C-R16), (b) 기억 조건별 1위 변경 비율, (c) 손 표 예측과 Jev 1위의 일치율. **통과 기준(가설)**: 의미 연관 조건에서 손 표와 Jev의 1위가 25% 이상 다르고, 그 차이를 사람 3명 중 2명 이상이 "납득"으로 평가.
- **플레이 A/B**: 같은 지도·같은 시작 상태, 참가자 12명(가설). 교차 설계로 각자 Jev 버전 2판 + 손 표 버전 2판, 순서는 무작위. 참가자에게는 "버전 1/2"로만 알린다.
- **관찰 지표**
  - 판정 사례 분류: 판마다 의도가 표시될 때 "예상했다 / 놀랐지만 납득 / 납득 안 됨"을 기록(사후 영상 회고).
  - 소문 관련 전략 발화 빈도("저 사람한테 소문 가기 전에", "모자를 흘려서").
  - 겉모습 다양성: 판당 사용한 겉모습 조합 수, 판 사이 반복률(Q6).
  - 블라인드 질문: "어느 버전의 경비원이 서로 이야기를 나누는 것처럼 느껴졌나?", "어느 쪽을 한 판 더 하겠나?"
- **판정 기준(가설)**: Jev 버전에서 "놀랐지만 납득" 비율이 10%p 이상 높고, 블라인드 선호가 2/3 이상이면 원칙 2 통과 신호. 차이가 없으면 소문 판정을 손 표로 확정하고 Jev의 역할을 재검토한다.

## 8. 대표 플레이 예시 (규칙 적용)

배경(임시): 근미래 해상 데이터센터. 경비원 6명 중 3명만 등장.
- 경비원 **한**(Z1 로비, 페르소나: "20년차, 규정보다 얼굴을 기억한다", "작업자에게 관대", "점심 이후 피곤"), **세라**(Z2 작업동, "신입, 체크리스트대로", "작업복에 민감", "무전을 자주 한다"), **오도**(Z3 서버실 앞, "전직 주방장", "음식 냄새에 관대", "외부인에게 엄격").
- 무전망: 한–세라(지연 2, 중계기 R1 경유), 세라–오도(지연 1).

1. 턴 3, 로비. 겉모습: 형광 조끼 / 케이블 뭉치 / "급히 걷는다" / 없음. J1(한, 기억 없음 → 사전 계산 표): **자기 일 계속(확고)**. 통과.
2. 턴 5, 작업동 복도. 세라 앞. J1(세라, 의심 0, 기억 없음 → 표): **무전 보고(보통)**, J1b = 옷(형광 조끼), J1c 하이라이트 = 옷. 경비원 실행 단계에 소문 "작업동에서 형광 조끼" 생성 → 오도 기억에 턴 6 도착 예정, 한에게는 턴 7 도착 예정.
3. 턴 6 계획. 오도가 있는 서버실 앞으로 가야 한다. 조끼를 그대로 입으면 H2(정확 일치 1개, 하한 미적용)는 걸리지 않지만 기억이 있으므로 실시간 판정이다. 관찰 토큰 1 사용: 가상 장면(조끼 / 케이블 / 급히 걷는다) → 오도 **말을 검(보통)**, 하이라이트 = 기억 "무전: 작업동에서 형광 조끼".
4. 탕비실로 우회한다(이동). 조끼를 버리고(상호작용) 다음 턴에 "커피 쟁반"을 줍는다. 관찰: 오도 J1(가상: 작업복 상의 / 커피 쟁반 / 급히 걷는다, 기억에 조끼 소문 있음) → **자기 일 계속(망설임)** → 망설임 규칙에 따라 덜 엄격한 "자기 일 계속" + 의심 +1. 하이라이트 = 손(커피 쟁반). 페르소나(주방장)와 쟁반의 의미 연관이 작동한 사례다(가설상 Jev 고유 효과).
5. 턴 8, 서버실 앞 통과. 오도의 의심은 1이다. 같은 차림으로 다시 지나가면 위험하다는 정보가 된다.
6. 턴 9. 목표물을 회수한 뒤 R1 중계기를 끈다(한–세라 무전 차단). 한은 조끼 소문을 받지 못한 상태로 남는다. 출구가 로비이므로 조끼를 다시 입는 쪽이 유리할 수 있지만, 조끼는 탕비실에 있다. 돌아갈 2턴을 쓸 것인가?

## 14. 종이 프로토타입 규칙 요약 (1쪽, 사람이 Jev 역할)

**준비물**: 방 카드 8장(선으로 연결해 배치), 경비원 카드 4장(페르소나 3문장, 순찰 경로, 의심 칸 0~2, 기억 칸 5), 물건 카드 16장, 행동 카드 6장, 대답 카드 3장, 소문 토큰(요소 이름을 쓴 포스트잇), 관찰 토큰 12개, 턴 기록지, 경계 단계 표시판.

**역할**: 플레이어 1명, 진행자 1명(규칙·소문 이동 담당), **Jev 역할 1명**(진행자와 다른 사람).

**Jev 역할 규칙**(C의 Q19 준수)
1. 경비원 카드, 현재 장면 4요소, 기억 칸만 보고 판단한다. 플레이어의 의도나 표정은 보지 않는다(칸막이).
2. 출력은 세 가지만 말한다. 반응(5개 중 하나) + 확신(확고/보통/망설임) + 가장 영향 준 것(요소 1개). **설명은 금지한다.**
3. 같은 장면·같은 기억이 다시 나오면 기록지를 보고 같은 답을 한다(캐시).
4. **오류 주입**: 진행자가 몰래 주사위를 굴려 6이 나오면, Jev 역할에게 "이번엔 상식과 다르게" 쪽지를 준다(약 1/6).
5. 무전 보고를 고르면 "무엇을 먼저 말하겠나"(요소 1개)도 답한다.

**턴 진행**: 소문 도착(진행자가 포스트잇을 경비원 기억 칸으로 옮김) → 플레이어 계획(관찰 토큰을 내면 Jev 역할에게 가상 장면 판정을 받음, 기록) → 이동 + 상호작용 1 → 경비원 실행 → 같은 방 경비원 판정 → 의도 카드를 경비원 위에 올려 둠.

**하드 규칙**(진행자가 Jev 역할보다 먼저 적용): H1 보안 구역 무단 개방 = 신분 확인. H2 기억과 같은 요소 2개 이상 = 최소 눈여겨봄. H3 경계 3 + 보안 구역 = 최소 말을 검. 망설임 = 덜 엄격한 쪽 + 의심 +1.

**종료**: 목표물 + 출구 = 승리. 체포, 경보 2회, 30턴 = 패배.

**기록할 것**: 판정마다 플레이어의 사전 예측(말로)과 실제 결과, "놀람/납득" 체크, 소문 관련 발화, 관찰 사용 위치, 판 시간.

**손 표 버전 진행**: Jev 역할 대신 진행자가 7.1의 덧셈 표를 적용한다. 플레이어에게는 어느 버전인지 알리지 않는다.
