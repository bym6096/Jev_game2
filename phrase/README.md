# 말 조각 (회색 박스)

확인하려는 것은 하나다. **말 조각을 모아 조합하고, 그 말로 상황을 헤쳐 나가는 게 재밌는가.** 배경은 `../LESSONS.md`에 있다.

실행: `python3 phrase/server.py` → http://localhost:8020 (키는 `JEV_API_KEY`, 클라우드에서는 프록시가 붙인다)

## 규칙 (모든 수치와 내용은 임시)
- 런은 상황 6개(12개 중 무작위)로 이뤄지고 목숨은 3개다. 주머니에는 처음에 조각 14개가 있고, 손에는 7개를 든다.
- 상황마다 진척 3을 채워야 한다. **내밀기 3번, 떠보기 2번**을 쓸 수 있다.
- 손의 조각을 순서대로 최대 3개 눌러 말을 만든다(예: "따뜻한 노래").
  - **떠보기**: Jev 판정 확률만 본다. 조각은 쓰지 않는다.
  - **내밀기**: 그 확률대로 굴린다. 바늘이 떨어진 칸이 결과다(대성공 +3 / 통함 +2 / 조금 +1 / 무반응 0 / 역효과 −1). 쓴 조각은 버림 더미로 간다.
- 같은 상황에 같은 말을 내밀면 런 안에서는 늘 같은 확률이 나온다(캐시).
- 3번 안에 진척을 못 채우면 목숨이 1 깎인다. 상황이 끝날 때마다 새 조각 1개를 얻거나, 조각 1개를 버린다.

## Jev 질문 (`server.py`)
- `outcome`: 이 말을 내밀면 상황이 어떻게 되는가 (5단계)
- `how`: 주로 어떤 식으로 작용하는가 (달램, 웃김, 겁줌, 줌, 속임, 직접 해결, 어리둥절, 불쾌)

## 첫 확인 (2026-11-11, 같은 말 × 다른 상황)
기대 진척(확률 가중)을 보면 금화는 문지기 +2.24, 우는 아이 +0.08, 늑대 −0.05였다. "따뜻한 자장가"는 우는 아이 +1.28, 졸고 있는 문지기 +0.96(계속 재운다는 해석), 늑대 −0.07이었다. 상황에 따라 판정이 갈려서 만능 조각은 없어 보인다.

## 아직 안 정한 것 / 볼 것
- 사람이 해 보고 **어디서 멈추고, 무엇을 반복하는지** 본다.
- 조각마다 성격(형용사/명사), 조각 수에 따른 보너스·비용, 상황의 연쇄(앞 상황의 결과가 다음 상황을 바꾸는 것), 상점·정산.
- 테마와 내용은 자리 표시일 뿐이다(디렉터가 정한다).
