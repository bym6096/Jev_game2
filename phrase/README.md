# 한 줄 공방 (회색 박스)

확인하려는 것은 하나다. **문장 틀의 칸에 말 조각을 골라 넣어, 의외의 멋진·웃긴·신비한 한 줄을 짓는 게 재밌는가.** 왜 이렇게 만들었는지는 `DESIGN.md`, 배경은 `../LESSONS.md`에 있다.

## 실행
- **웹 (Vercel)**: 새 프로젝트를 이 저장소로 만들고 **Root Directory = `phrase`**, 환경 변수 `JEV_API_KEY`를 넣는다. 선택으로 `ACCESS_CODE`를 넣으면 주소 끝에 `?code=그값`을 붙여야 판정이 된다. 빌드 설정은 필요 없다.
- **로컬**: `python3 phrase/server.py` → http://localhost:8020

## 하는 법
1. 의뢰서를 읽는다. 무엇을 짓는지(향수 이름, 간판 한 줄…), 의뢰인이 원하는 결(신비+멋짐…), 특수 규칙이 적혀 있다.
2. 문장 틀의 칸(이름: 어떤·무엇의·어떤·무엇 / 한 줄: 부름·어떤·누가·어떤·무엇을·어떻게·부정·확신·한다)에 조각을 넣는다. 칸은 비워 둬도 된다. "무엇을" 칸은 격을 바꿀 수 있다(무엇을 / 누구에게 / 무엇처럼 / 무엇과 / 어디서). 한 줄이면 말투도 고른다.
3. **시안 보내기**: 점수 = 채택(의뢰인이 받아들이는 정도) × 결 배율(원하는 결 적중 + 표현의 새로움). 시안 3개의 합으로 목표 점수를 넘기면 계약이 성사된다. 의뢰인은 앞선 시안을 기억해서, 비슷한 걸 또 보내면 덜 반긴다.
4. **안 쓴 조각 다시 뽑기**: 의뢰당 2번.
5. 계약이 끝나면 조각(★ 희귀 포함)이나 말투 하나를 얻거나, 조각 하나를 버린다. 6개 의뢰, 평판 3.

## 파일
- `data.json`: 조각(범주·감각 영역), 문장 틀, 격, 말투, 결, 의뢰서
- `jev.py`: 한국어 렌더러 + 규칙 검사 + Jev 판정 + 점수 (로컬·Vercel 공용)
- `index.html`: 화면 (같은 렌더러의 JS판)
- `server.py`: 로컬 서버, `api/judge.py`: Vercel 함수
