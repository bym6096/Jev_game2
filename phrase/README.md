# 말 짓기 (회색 박스)

확인하려는 것은 하나다. **받은 말 조각과 말투로 한 줄을 지어 상대를 움직이는 게 재밌는가.** 왜 이렇게 만들었는지는 `DESIGN.md`, 배경은 `../LESSONS.md`에 있다.

## 실행
- **웹 (Vercel)**: 새 프로젝트를 이 저장소로 만들고 **Root Directory = `phrase`**, 환경 변수 `JEV_API_KEY`를 넣는다. 선택으로 `ACCESS_CODE`를 넣으면 주소 끝에 `?code=그값`을 붙여야 판정이 된다(남이 키를 쓰지 못하게). 빌드 설정은 필요 없다(`index.html`·`data.json`은 정적 파일, `api/judge.py`는 파이썬 함수).
- **로컬**: `python3 phrase/server.py` → http://localhost:8020 (키는 `JEV_API_KEY`, 클라우드에서는 프록시가 붙인다)

## 하는 법
1. 손에 든 조각(색 = 기능)을 눌러 최대 4개 넣는다. 넣은 파란 조각(누구·무엇)을 누르면 역할이 바뀐다(누가 / 무엇을 / 누구에게).
2. 말투(단언, 질문, 부탁 …)를 고른다. 아래에 완성된 문장이 보인다.
3. **떠보기**는 확률만 본다. **말하기**는 그 확률대로 굴리고, 상대의 반응이 대화에 남는다. 상대는 앞서 한 말을 기억한다.

## 파일
- `data.json`: 조각, 말투, 상황, 반응
- `jev.py`: 한국어 렌더러 + Jev 판정 + 요청 검증 (로컬·Vercel 공용)
- `index.html`: 화면 (같은 렌더러의 JS판)
- `server.py`: 로컬 서버, `api/judge.py`: Vercel 함수
